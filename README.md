# math10 — мини-уроки математики

Интерактивные уроки для самостоятельных и совместных занятий математикой в 10 классе. Сначала разбираемся, зачем нужна идея и почему она работает, затем переходим к формулам и практике.

## Как открыть

Скачайте проект и откройте [index.html](index.html) в обычном браузере. Сервер, установка пакетов и сборка не нужны. Каждый урок можно открыть отдельно. Сайт не опубликован на хостинге.

Список готовых материалов ведём в [LESSONS.md](LESSONS.md). Сейчас подготовлены синус и косинус, тангенс и котангенс, бином Ньютона, преобразования графиков, вероятность и комбинаторика, тригонометрические уравнения, формулы сложения и двойного угла. Личные результаты обучения в публичном реестре не хранятся.

Новые страницы работают без интернета. В двух исходных уроках шрифты необязательно загружаются с Google Fonts; при отсутствии сети используются системные шрифты. Задания и рисунки выполняются локально. Отметки прогресса хранятся только в браузере, если доступен localStorage; между устройствами не синхронизируются.

## Проверка проекта

Нужен только Python 3.9 или новее, без сторонних пакетов:

```powershell
python3.12 scripts/check_project.py
```

Если Python доступен под другим именем, используйте `python` или `py -3`. Скрипт проверяет структуру проекта, внутренние ссылки, якоря, идентификаторы HTML и наличие уроков в каталоге и реестре. Он не исполняет JavaScript и не проверяет математическую корректность: для этого нужны проверки из [QUALITY.md](docs/QUALITY.md).

## Приватность

В Git храним учебные материалы и техническую документацию. Личные сведения и результаты занятий остаются вне репозитория. Авторство коммитов нейтральное: `math10 contributors <contributors@math10.invalid>`; настройка действует только в этом проекте.

```powershell
python3.12 scripts/check_privacy.py --staged
python3.12 scripts/check_privacy.py --history main
```

Проверяются типовые признаки секретов, личных email, домашних путей и метаданные коммитов. Значения совпадений не выводятся. Это эвристическая проверка, которую дополняют просмотром diff. Изменение истории не удаляет сторонние копии и не подтверждает очистку серверных кешей.

Текущие файлы обезличены; коммиты используют нейтральную identity. Объём очистки исходной истории и результат синхронизации зафиксированы в [спецификации 005](specs/005-public-privacy.md). Проверка истории должна проходить перед каждой отправкой новых изменений.
