Свойства функций по графику

График может рассказать, когда величина положительна, где она растёт и какого значения достигает. Для этого не обязательно знать формулу — нужно научиться читать рисунок.

Понадобятся координаты точки и сравнение чисел. Функцию, аргумент и запись промежутков объясним внутри.

Два вопроса — две оси

Функция — правило, которое каждому допустимому числу x ставит в соответствие ровно одно число y. Число x называют аргументом, y = f(x) — значением функции. График состоит из точек (x; f(x)). Чтобы прочитать f(2), найди 2 по горизонтали, дойди до графика и прочитай высоту по вертикали.

Где можно выбирать x?

Область определения D(f) — все допустимые значения аргумента. Мысленно опусти график на горизонтальную ось: какие x заняты?

Какие y получаются?

Множество значений E(f) — все значения, которые функция принимает. Мысленно сдвинь график к вертикальной оси: какие высоты заняты?

Запись [−4; 4] включает оба конца; (−4; 4) их исключает. В [−4; 4) левый конец включён, правый — нет. Квадратная скобка означает «входит», круглая — «не входит». Отдельное значение записывают, например, {2}.

Закрашенная точка принадлежит графику. Выколотая точка — кружок без заливки — не принадлежит. Но исключённая точка на одной высоте ещё не исключает эту высоту из E(f): её может давать другая точка.

В мастерской ниже дана вся функция: за крайними точками продолжения нет. Если же на рисунке показан только фрагмент графика, по рамке нельзя определять всю область определения и все значения.

На полях

Попросите показать область определения рукой вдоль горизонтальной оси, а множество значений — вдоль вертикальной. Если ответ один и тот же, вернитесь к координатам точки.

Нули и знак: смотри на высоту

Нули функции — значения x, при которых f(x) = 0. На графике это абсциссы точек на горизонтальной оси. Если график касается оси и возвращается обратно, нуль всё равно есть; знак через него может не меняться.

f(x) > 0 — график выше оси x.
f(x) < 0 — график ниже оси x.

В исходной ломаной мастерской нули: −3, −1, 1 и 4. Например, между −3 и −1 график выше оси. При x = −2 значение равно 2, а при x = 0 значение равно −2. Сам x может быть отрицательным, а f(x) — положительным.

При строгом неравенстве нули не входят в ответ. Для f(x) ≥ 0 добавляем нули, которые принадлежат области определения. Выколотый конец на оси нулём функции не является.

Метод интервалов позволяет находить знак по формуле. Здесь ту же задачу решаем по расположению графика относительно оси.

На полях

Попросите отдельно назвать x и f(x) в точке (−2; 2). Полезный вопрос: «Отрицательный аргумент обязательно даёт отрицательное значение?»

Растёт — не значит положительна

Читай график слева направо. Функция возрастает на промежутке, если для любых двух аргументов x₁ < x₂ из него выполняется f(x₁) < f(x₂). Убывает, если f(x₁) > f(x₂). Это строгое сравнение: на горизонтальном участке значения одинаковы, функция там постоянна.

В исходной ломаной от −4 до −2 функция возрастает: значение меняется от −2 до 2. Сначала график ниже оси, затем выше — направление роста при этом не меняется. От −2 до 0 функция убывает, хотя часть этого пути проходит выше оси.

Самое высокое — и достигается ли оно?

Наибольшее значение — значение функции, не меньшее всех остальных. Наименьшее определяют так же, заменив «не меньшее» на «не большее». Это числа y, а аргументы x показывают, где они достигаются.

У исходной ломаной наибольшее значение 2 достигается при x = −2 и x = 2; наименьшее −2 — при x = −4 и x = 0.

Для y = x на (−3; 3) нет ни наибольшего, ни наименьшего значения: 3 и −3 не достигаются. Как бы близко ты ни подошёл к 3, найдётся допустимое значение ещё больше.

Возрастание и убывание называют строгой монотонностью. Промежутки монотонности в мастерской записаны с вершинами, если они принадлежат графику. Два соседних промежутка могут иметь общий конец: это не нарушает строгого сравнения внутри каждого.

На полях

Сравните два вопроса: «Где график выше оси?» и «Где он идёт вверх?». Для крайних значений попросите назвать сначала высоту, затем аргументы. Термины локального экстремума пока не нужны.

Исследуй весь график

Выбери вид графика, сдвинь его вверх или вниз, включи или исключи концы. Сначала предскажи, что изменится в D(f), E(f), нулях и промежутках возрастания, затем сравни со свойствами под рисунком.

Синяя линия — график. Красная точка и пунктир — выбранные координаты. Кружок без заливки исключает точку.

Вершины исходной ломаной без сдвига

(−4; −2), (−2; 2), (0; −2), (2; 2), (4; 0). Соседние вершины соединены отрезками; все промежуточные точки входят. Координаты заданы точно, ответы читаются по ним, а не по толщине линии.

Исследуй три случая: исключи левый конец исходной ломаной — останется ли минимум? Выбери возрастающий отрезок и исключи оба конца — достигаются ли крайние высоты? Выбери постоянный участок и сдвиг −2 — сколько получится нулей?

Вертикальный сдвиг добавляет одно число ко всем значениям. Подробнее это объясняет урок о преобразованиях графиков; направление роста при таком сдвиге сохраняется.

На полях

Пусть сначала прозвучит прогноз, а уже потом меняется контрол. На постоянном участке нулей может быть целый промежуток. Исключение конца не всегда убирает его высоту из множества значений.

Проверь чтение графика

Задания об исходной ломаной относятся к точным вершинам, указанным выше, независимо от текущих настроек мастерской. У каждой задачи есть подсказка и решение.

1. Область определения

Вся функция задана отрезком от (−3; −3) до (3; 3). Левый конец выколот, правый закрашен. Найди D(f).

Подсказка

Смотри на горизонтальную ось и заливку концов.

Решение

Допустимы x больше −3 и не больше 3: D(f) = (−3; 3].

2. Аргумент и значение

На графике есть точка (−2; 2). Что верно?

Подсказка

Первая координата — аргумент, вторая — значение.

Решение

При аргументе −2 значение равно 2, значит f(−2) = 2.

3. Строго положительна

У исходной ломаной из мастерской выбери все x, при которых f(x) > 0.

Подсказка

Нужны части выше оси, а не идущие вверх.

Решение

Выше оси находятся участки между −3 и −1 и между 1 и 4. Нули исключены: (−3; −1) ∪ (1; 4).

4. Возрастание

Где исходная ломаная возрастает?

Подсказка

Двигайся слева направо и сравнивай высоты.

Решение

На [−4; −2] и [0; 2] любому большему аргументу соответствует большее значение.

5. Значение и место

Как описать наибольшее значение исходной ломаной?

Подсказка

Ищи самую высокую занятую высоту.

Решение

Наибольшая высота равна 2. Она достигается в двух вершинах: при x = −2 и x = 2.

6. Открытые концы

Дана y = x только на (−3; 3). Что с наибольшим значением?

Подсказка

Любое выбранное x меньше 3 можно увеличить, оставаясь в промежутке.

Решение

Значение 3 не достигается. Для любого x < 3 число (x + 3)/2 ближе к 3 и даёт большее значение. Наибольшего значения нет.

7. Та же высота в другом месте

У исходной ломаной исключили левый конец (−4; −2). Что стало с наименьшим значением?

Подсказка

Проверь остальные точки на той же высоте.

Решение

Точка (0; −2) осталась на графике. Поэтому наименьшее значение по-прежнему −2, теперь только при x = 0.

8. Целый промежуток нулей

Функция равна 0 на всём [−1; 1]. Какие у неё нули?

Подсказка

Нуль функции — аргумент, который даёт значение 0.

Решение

Каждый аргумент из [−1; 1] даёт ноль. Поэтому нули заполняют весь промежуток; функция постоянна и не является строго возрастающей или убывающей на нём.

На полях

После верного ответа попросите объяснить, какая часть рисунка или определения его подтверждает. Если неверно, сначала откройте подсказку; затем сравните ход рассуждения с решением.

Шесть вопросов к графику

  1. Какие x допустимы? Это D(f).
  2. Какие y достигаются? Это E(f).
  3. Где график на оси x? Это нули.
  4. Где он выше или ниже оси? Это знак функции.
  5. Где слева направо высоты строго растут, убывают или остаются одинаковыми?
  6. Какие крайние высоты достигаются и при каких аргументах?

Всегда проверь, дан ли весь график, входят ли концы и не достигается ли исключённая высота в другой точке.

Преобразования графиков объясняют изменение зависимости, а метод интервалов — поиск знака по формуле. Теперь можно сопоставлять эти способы.

На полях

Урок можно разделить после раздела об изменении. Понимание видно по различению аргумента и значения, знака и роста, высоты и места её достижения.
