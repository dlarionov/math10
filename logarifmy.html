Логарифмы

Количество удваивается каждый час. Через сколько часов оно вырастет в восемь раз? Теперь известен результат, а найти нужно показатель степени.

Пригодятся степени и корни и показательная функция. После графика можно сделать перерыв. Ответы и настройки не сохраняются.

1. Результат известен — ищем показатель

За один час множитель равен 2, за два — 4, за три — 8. Значит, ответ — 3 часа. Запись log₂8 = 3 читается «логарифм восьми по основанию два равен трём». Логарифм — число, отвечающее на вопрос: в какую степень возвести основание, чтобы получить аргумент? Аргумент — число под знаком логарифма.

logab = c ⇔ ac = ba > 0, a ≠ 1, b > 0; c — действительное число.

Почему эти условия? Степень положительного основания с любым действительным показателем всегда положительна: ноль и отрицательные аргументы получить нельзя. Основание 1 даёт только 1: для аргумента 1 подходит любой показатель, для остальных — ни один. Отрицательное основание не позволяет брать все действительные показатели, например 1/2. Поэтому его тоже исключаем.

При допустимом основании показательная функция непрерывна, строго возрастает или убывает и принимает все положительные значения. Поэтому для каждого b > 0 нужный показатель существует и единственен. Он может быть отрицательным, дробным или иррациональным.

log₂(1/8) = −3, потому что 2−3 = 1/8.
log₉3 = 1/2, потому что 91/2 = 3.
log₂3 ≈ 1,585: точной конечной десятичной записи здесь нет.

Для вас

Попросите перевести одну запись в другую. Если ученица называет логарифм действием деления, вернитесь к вопросу о показателе.

2. Две записи одного факта

Сначала предскажи: каким будет log₂b, если b = 1/4?

Подсказка

Какой показатель у двойки даёт четверть?

Решение

−2, так как 2−2 = 1/4. Отрицателен показатель, а аргумент положителен.

2³ = 8 ⇔ log₂8 = 3.

Меняй показатель: при c = 0 аргумент всегда 1. Поставь a = 1/2 и c = −2: получишь b = 4. Для убывающей степени большой аргумент соответствует меньшему показателю. Если аргумент округлён, обратная запись с этим округлённым числом тоже приближённая.

Для вас

Выберите сначала целый показатель, затем половину. Попросите объяснить знак результата до вычисления.

3. График: вход и выход меняются местами

У показательной функции 2³ = 8 вход 3 даёт выход 8. У логарифмической вход 8 даёт выход 3. Точки (3;8) и (8;3) симметричны относительно прямой y = x. График логарифма получается отражением показательного графика.

Предскажи: где будет точка (1; loga1) при смене основания?

Подсказка

Любое допустимое основание в нулевой степени равно 1.

Решение

Всегда (1;0). Это общая точка всех логарифмических графиков.

log₂4 = 2. Точка (4;2).

Окно: 0 ≤ x ≤ 8, −4 ≤ y ≤ 4. Кривая продолжается за границами окна; ось x = 0 не входит в область определения. При x → 0 справа график не заканчивается, а неограниченно уходит вниз (a > 1) или вверх (0 < a < 1).

y = logax: x > 0; y — любое действительное число.a > 1 — возрастает; 0 < a < 1 — убывает. Логарифм может быть отрицательным; его аргумент — только положительным.

Для вас

После этого шага можно остановиться. Попросите сравнить log₂(1/2) и log₁/₂(1/2): ответы −1 и 1, хотя аргумент одинаков.

4. Почему произведение превращается в сумму

Пусть u = ap и v = aq. Тогда uv = ap+q: умножение значений складывает показатели. Значит, логарифм произведения равен сумме логарифмов. Деление вычитает показатели, а возведение в степень умножает их.

loga(uv) = logau + logav
loga(u/v) = logau − logav
loga(ur) = r logauЗдесь a > 0, a ≠ 1, u > 0, v > 0, r — любое действительное число. Для третьего правила достаточно условий на a, u и r.

Например, log₂(4 · 8) = log₂32 = 5, и log₂4 + log₂8 = 2 + 3 = 5. Но логарифм суммы так раскладывать нельзя: log₂(2 + 2) = 2, а log₂2 + log₂2 = 2 лишь случайно совпали. При 2 + 6 получаем 3, тогда как log₂2 + log₂6 = log₂12 ≠ 3.

log₂((−2)²) = log₂4 = 2 существует, но 2 log₂(−2) не определено. Нельзя выносить показатель, забыв условие u > 0. Для ненулевого u верна запись loga(u²) = 2 loga|u|.

Если основания различаются

Из b = ac получаем logkb = c logka. Разделим на ненулевой logka:

logab = logkblogkaa > 0, a ≠ 1, b > 0, k > 0, k ≠ 1.

Например, log₄8 = log₂8 / log₂4 = 3/2. Обозначение lg — основание 10, ln — основание e ≈ 2,718. Калькулятор вычисляет log₂3 как ln 3 / ln 2 ≈ 1,585.

Для вас

Попросите обосновать одно свойство степенями. Не требуйте запоминать формулу без её условий.

5. Сначала условия, затем преобразование

Уравнение

log₃(x − 1) = 2. Сначала x − 1 > 0, то есть x > 1. По определению x − 1 = 3² = 9, значит, x = 10. Проверка: 10 > 1 и log₃9 = 2.

Сравнение при убывании

log1/2x > 1. Сначала x > 0. Число 1 = log1/2(1/2). Функция убывает: большее значение получается при меньшем аргументе. Поэтому x < 1/2. Вместе: 0 < x < 1/2. Граница 1/2 даёт равенство и не входит, ноль запрещён.

При основании больше 1 знак сравнения аргументов сохраняется. Например, log₂x ≤ 3 равносильно 0 < x ≤ 8: граница 8 включена, ноль исключён.

Для вас

Попросите назвать обе границы ответа и объяснить каждую: условие существования и знак сравнения имеют разные причины.

6. Восемь задач

Реши самостоятельно, затем сравни ход с решением. Исправлять ответы можно сколько угодно.

1. Вычисли log₂(1/8).

Подсказка

Представь 1/8 как степень двойки.

Решение

2⁻³ = 1/8, поэтому log₂(1/8) = −3.

2. Вычисли log₉3.

Подсказка

Какой корень из 9 равен 3?

Решение

91/2 = 3, поэтому ответ 1/2 = 0,5.

3. Вычисли log₅1.

Подсказка

Реши 5ᶜ = 1.

Решение

5⁰ = 1, поэтому ответ 0.

4. Вычисли log₂3 + log₂(8/3).

Подсказка

Умножь 3 и 8/3.

Решение

Аргументы положительны. Сумма равна log₂(3 · 8/3) = log₂8 = 3.

5. Реши log₃(x − 1) = 2.

Подсказка

x − 1 = 3².

Решение

Условие x > 1. Из x − 1 = 9 получаем x = 10. Подстановка даёт log₃9 = 2.

6. Реши log1/2x > 1.

Подсказка

Сравни с log₁/₂(1/2).

Решение

Функция убывает: x < 1/2. Вместе с x > 0 получаем 0 < x < 1/2.

7. Какая запись верна?

Подсказка

Вычисли log₂(3 + 5), а сумму логарифмов объедини в логарифм произведения.

Решение

log₂(3 + 5) = log₂8 = 3; log₂3 + log₂5 = log₂15 ≠ 3.

8. Какое выражение не определено в действительных числах?

Подсказка

Проверь основание и аргумент.

Решение

log₁4 не определён: 1ᶜ всегда равно 1. Остальные существуют: log₂1 = 0 и log₁/₂4 = −2.

Вводи число или дробь; запятая и точка допустимы. При округлении до 0,001 допуск равен 0,0005. Выражения со степенями и логарифмами в поле не вводятся.

Для вас

Попросите сначала проговорить смысл и условия. Верный ответ сам по себе ещё не показывает понимание; полезнее объяснение и проверка степенью.

Шпаргалка: найди показатель

logab = c ⇔ ac = b
loga1 = 0; logaa = 1
alogab = b; loga(at) = ta > 0, a ≠ 1, b > 0; t — любое действительное число.

Перед вычислением проверь основание и аргумент. Перед преобразованием проверь условия свойства. Перед сравнением вспомни, возрастает функция или убывает.

Объясни своими словами: почему log₂(1/8) отрицателен, хотя аргумент положителен? Почему log₁1 не равен единственному числу? Почему log₂(u + v) нельзя заменять суммой логарифмов? Придумай свой логарифм, равный −2, и проверь его степенью.
