функция

Количество удваивается каждый час. Через три часа оно вырастет в восемь раз. А что значит «через полчаса»? Разберись, как постоянный множитель превращается в кривую.

Сначала нужна идея степени: степени и корни. После третьего шага можно сделать перерыв. Ответы и настройки не сохраняются.

Занятие 1 · шаг 1

Прибавлять и умножать — разные истории

В начале есть 10 условных единиц. По первому правилу каждый час прибавляем 10, по второму — умножаем на 2. Сравни:

Час t0123
+10 каждый час10203040

В первом ряду одинаковы разности соседних значений. Во втором — отношения: следующее значение делим на предыдущее и каждый раз получаем 2. Прибавка во втором ряду меняется: 10, затем 20, затем 40.

N(t) = 10 · 2t для целых t ≥ 0.t — время в часах; N(t) — количество условных единиц. Число 10 — начальное количество, 2 — множитель за один час.

Предскажи. Если удвоение происходит равномерно по множителю, сколько будет через полчаса?

Подсказка

Два одинаковых получасовых множителя должны в произведении дать 2.

Решение

Каждые полчаса множитель √2, потому что √2 · √2 = 2. Поэтому через полчаса N = 10√2 ≈ 14,142. Значение 15 соответствует линейному прибавлению, а 20 — целому часу.

Само условие «каждый час удваивается» задаёт значения только в целые часы. Для промежуточных моментов мы дополнительно принимаем непрерывную модель: за любые равные промежутки времени количество изменяется в одно и то же число раз. Модель подходит не каждому реальному процессу; для счётных предметов дробные значения могут быть условной оценкой.

Для вас

Попросите назвать, что постоянно: прибавка или множитель. Не подменяйте удвоение за час прибавлением половины начального количества за полчаса.

Шаг 2 · исследование времени

Один час назад — обратное действие

Если каждый час умножать на q > 0, то при движении на час назад нужно делить на q. Через полчаса множитель √q. Так прежние правила степени получают смысл во времени:

N(t) = 10 · qt, q > 0.
N(0) = 10; N(−1) = 10/q; N(1/2) = 10√q.

Нулевой момент — выбранное начало отсчёта, отрицательное время — восстановление количества до этого момента по той же модели. При q = 1 количество постоянно.

Меняй множитель и время

q = 2; t = 1 ч. N(t) ≈ 20 условных единиц.

За час количество умножается на 2, за полчаса — на √2.

Выбранный целый час выделяется в таблице. При дробном t точное положение между столбцами показывает число в подписи. Здесь и далее интерактивные значения округлены до 0,001 и помечены ≈.

Попробуй q = 1/2: с увеличением времени количество уменьшается, но остаётся положительным. Затем выбери q = 1: время меняется, а количество — нет.

Для вас

Спросите, почему при t = −1 и q = 1/2 количество больше начального. Обратное действие к делению пополам — удвоение.

Шаг 3 · исследование графика

Показатель становится переменной

Уберём начальный множитель 10 и будем обозначать вход буквой x. В выражении ax число a постоянно, а переменная стоит в показателе. Это отличается от степенной функции y = xa, где показатель a постоянен, а меняется основание x. Например, y = 2x — показательная функция, а y = x² — степенная.

y = ax, a > 0, a ≠ 1.Такую функцию называют показательной. Условие a ≠ 1 исключает постоянную функцию y = 1.

Рациональные показатели уже знакомы: a1/2 = √a, a−1 = 1/a. Для иррационального x, например √2, его приближают рациональными числами всё точнее: 1,4; 1,41; 1,414… Значения a в этих степенях приближаются к одному положительному числу — так получают a√2. Здесь это идея продолжения степени; строгое построение оставим за рамками урока.

Сравни рост, убывание и постоянный случай

Синяя линия — y = aˣ, красная точка — выбранное x, пустая синяя точка — (0;1). Оси линейные. Окно фиксировано: −3 ≤ x ≤ 3, 0 ≤ y ≤ 9. Если ветвь или точка выше 9, их верхняя часть не видна; стрелка у края обозначает продолжение.

a = 2; x = 1; aˣ ≈ 2. График возрастает.

Точка (1; 2) внутри окна. Все значения функции положительны.

Выбери a = 1/2 и пройди от x = −3 до x = 3. Затем сравни с a = 2: одинаковые высоты встречаются при противоположных x. Это отражение относительно оси y, ведь (1/2)x = 2−x.

Для вас

Попросите предсказать направление до выбора основания. Отдельно проверьте a = 1: это полезный постоянный случай, но он исключён из определения показательной функции.

Здесь можно остановиться. Перед продолжением попросите назвать общую точку графиков без рисунка.

Занятие 2 · шаг 4

Что видно за пределами рисунка

Почему основание положительно

Нам нужна функция для каждого действительного x. При a = 0 уже x = −1 потребовал бы 1/0. При a < 0, например a = −2, значение при x = 1/2 потребовало бы √(−2), которого нет в действительных числах. Поэтому берём a > 0; a = 1 исключаем отдельно, потому что 1x = 1.

Куда может попасть значение

При a > 0 степень ax определена для любого действительного x и всегда положительна. Поэтому область определения — все действительные числа, а множество значений — все положительные числа: (0; +∞), если a ≠ 1. График проходит через (0;1), потому что a⁰ = 1.

При a > 1 и очень больших отрицательных x значения сколь угодно близки к нулю, но не равны ему. В другую сторону они растут без ограничения. При 0 < a < 1 направления меняются местами. Непрерывный график проходит через любую положительную высоту. Ось y = 0 называют горизонтальной асимптотой: график приближается к ней в одном из направлений, не достигая её. Из-за масштаба рисунка маленькие значения могут выглядеть почти нулевыми.

Почему одно основание растёт, другое убывает

Функция возрастает, если большему x соответствует большее y; убывает, если большему x соответствует меньшее y. Увеличим x на h > 0. По свойству степени:

ax+h = ax · ah.При a > 1 множитель aʰ > 1 — значение растёт. При 0 < a < 1 множитель 0 < aʰ < 1 — значение уменьшается.

Для положительного рационального h это следует из корней и целых степеней; для действительных h свойство сохраняется при непрерывном продолжении степени. Поэтому направление не зависит от выбранного участка экрана.

Предскажи. Может ли (1/2)x стать равным нулю при каком-нибудь действительном x?

Подсказка

При x = 0 значение равно 1. Дальнейшее деление пополам даёт положительные числа.

Решение

При любом конечном действительном x значение положительно. Стремиться к нулю и равняться нулю — разные утверждения. Бесконечность не является значением x из области определения.

Для вас

Спросите, почему маленькое число на экране не доказывает, что график пересёк ось. Свойство функции важнее округлённого изображения.

Шаг 5 · сравнение показателей

Одинаковое основание раскрывает показатель

Строго возрастающая или строго убывающая функция не принимает одно значение дважды. Поэтому при a > 0, a ≠ 1:

au = av ⇔ u = v.Знак ⇔ читается «равносильно»: каждое утверждение следует из другого.

Разобранное уравнение

32x−1 = 27. Представь 27 = 3³. Основания равны и допустимы, значит, 2x − 1 = 3, откуда x = 2. Проверка: 32·2−1 = 3³ = 27.

В неравенстве важно направление изменения функции:

При a > 1: au > av ⇔ u > v.
При 0 < a < 1: au > av ⇔ u < v.Для ≥ и ≤ рассуждение такое же, включая равенство на границе.

Убывание меняет знак

(1/2)x > 1/8. Запиши 1/8 = (1/2)³. Поскольку основание между 0 и 1, большее значение получается при меньшем показателе: x < 3. Проверка: x = 2 даёт 1/4 > 1/8; x = 3 даёт равенство и не входит в ответ.

Сравнивать показатели так можно при одинаковом допустимом основании. Например, из 2³ < 3² нельзя заключать, что 3 < 2. Основания разные. Уравнения, где привести к одному основанию неудобно, разберём в отдельном уроке о логарифмах.

Для вас

Попросите объяснить смену знака через убывающий график. При a = 1 равенство 1ᵘ = 1ᵛ выполняется и для разных u, v — поэтому условие a ≠ 1 существенно.

Шаг 6 · самостоятельная практика

Множитель, основание и знак

Сначала реши на бумаге. Подсказки и решения доступны сразу; можно возвращаться к задачам.

1. В начале 10 условных единиц. Количество удваивается каждый час. Сколько будет через 3 часа?

Подсказка

Запиши 10 · 2³.

Решение

10 · 2³ = 10 · 8 = 80 условных единиц.

2. В начале 10 условных единиц. Каждый час остаётся половина. Сколько будет через 2 часа?

Подсказка

Вычисли 10 · (1/2)².

Решение

10 · (1/2)² = 10/4 = 2,5 условной единицы. Это положительное число.

3. Реши 2x = 1/8.

Подсказка

Представь 1/8 как степень двойки.

Решение

1/8 = 2−3, значит, x = −3. Проверка: 2−3 = 1/2³ = 1/8.

4. Реши 32x−1 = 1/27.

Подсказка

1/27 = 3−3. Приравняй показатели.

Решение

2x − 1 = −3, поэтому 2x = −2 и x = −1. Проверка: 32·(−1)−1 = 3−3 = 1/27.

5. Реши (1/2)x > (1/2)³.

Подсказка

Большее значение убывающей функции получается при меньшем аргументе.

Решение

x < 3. При x = 2 получаем 1/4 > 1/8. Точка x = 3 даёт равенство, поэтому не входит.

6. Реши 2x+1 ≤ 8.

Подсказка

Сравни x + 1 и 3, сохрани нестрогий знак.

Решение

2x+1 ≤ 2³ равносильно x + 1 ≤ 3, значит, x ≤ 2. При x = 2 обе части равны 8, граница включена.

7. Сколько действительных решений у 2x = 0?

Подсказка

Может ли график достичь оси y = 0?

Решение

Решений нет: 2x > 0 при любом действительном x. Даже очень большое отрицательное x не даёт ноль.

8. Какая функция является показательной по определению этого урока?

Подсказка

Для отрицательного основания проверь x = 1/2; для основания 1 вспомни постоянный случай.

Решение

y = (1/2)x: основание положительно и не равно 1. Функция y = 1x постоянна; (−2)x не определено для всех действительных x.

Вводи число или дробь; запятая и точка допустимы. При округлении до 0,001 проверка допускает погрешность не более 0,0005. Выражения со степенями в этих полях не вводятся.

Для вас

Перед ответом попросите назвать основание, его положение относительно 1 и смысл показателя. Проверка одной точки полезна для обнаружения ошибки, но не заменяет решения всего неравенства.

Шпаргалка

Три вопроса перед решением

Что постоянно: прибавка или множитель? Каково основание: больше 1 или между 0 и 1? Приведены ли обе части к одному основанию?

y = ax, a > 0, a ≠ 1.
x — любое действительное число; y > 0.
a⁰ = 1; a−x = (1/a)x.a > 1 — возрастает; 0 < a < 1 — убывает. При одинаковом основании равенство значений даёт равенство показателей, а убывание меняет знак сравнения показателей.

Объясни своими словами, почему 2−3 положительно, почему все показательные графики проходят через (0;1) и почему 2x = 0 не имеет решений. Придумай пример постоянной прибавки и пример постоянного множителя.

Для повторения: степени и корни. Для графических связей: преобразования графиков. Продолжение: логарифмы — ищем неизвестный показатель.

Для вас

Признак понимания: ученица объясняет дробное время через корень, различает убывание и отрицательность значений, проверяет границу и основание перед решением неравенства.
