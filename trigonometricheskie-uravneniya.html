Одна высота.
Сколько углов?

Точка на колесе может оказаться на одной высоте дважды за оборот. А если колесо крутится дальше? Научимся находить все решения тригонометрического уравнения и выбирать нужные.

Нужны единичная окружность и радианы. По пути повторим главное. Время — ориентир: можно остановиться после любого шага.

Занятие 1 · шаг 1

Уравнение спрашивает об угле

Обычно мы знаем угол и ищем синус. Теперь наоборот: знаем высоту точки и ищем все углы, которые к ней приводят. На единичной окружности радиуса 1 cos x — горизонтальная координата, sin x — вертикальная.

Угол отсчитываем от положительного направления горизонтальной оси: против часовой стрелки — плюс, по часовой — минус. Измеряем в радианах: полный оборот 2π = 360°, половина оборота π = 180°. Поэтому 30° = π/6, 90° = π/2. Повторение: синус, косинус и радианы.

Проведи линию на нужном уровне

Для sin x = a ищи высоту a, для cos x = a — горизонтальную координату a. Меняй уровень: сколько точек пересечения получится?

sin x = 0,5: 2 точки за один оборот 0 ≤ x < 2π. Углы π/6 и 5π/6.

Точки — положения на окружности. Каждому положению соответствует бесконечно много углов с разным числом оборотов. Уровень вне [−1; 1] не пересекает окружность.

При sin x = 1/2 горизонтальная линия пересекает окружность справа и слева. Первая точка соответствует π/6. У второй та же высота, а угол равен π − π/6 = 5π/6. Один ответ π/6 теряет вторую точку.

Предсказание 1. Для sin x = 1/2 один угол — π/6. Какой второй угол в промежутке [0; 2π)? Квадратная скобка включает конец, круглая исключает.

Подсказка

Отрази точку относительно вертикальной оси. Высота не меняется.

Решение

π − π/6 = 5π/6. При −π/6 и 7π/6 синус отрицателен, их высота равна −1/2.

Для вас

Попросите сначала показать обе точки пальцем. Признак понимания: ученица объясняет вторую точку равной высотой, а не только вспоминает формулу.

Сравните a = 0, a = 1 и a = 1,5. При касании точка одна, за пределами окружности точек нет.

Ответы и настройки этого урока не сохраняются.

Шаг 2 · не потерять обороты

Точка та же, угол другой

Прибавь к углу полный оборот 2π: точка вернётся на место, её координаты сохранятся. Это периодичность. Можно сделать два оборота, три или повернуться назад. Поэтому для sin x = 1/2 ответ состоит из двух серий:

x = π/6 + 2πk   или   x = 5π/6 + 2πk,k ∈ ℤ: k — любое целое число (…, −2, −1, 0, 1, 2, …). В каждой серии k выбирается независимо.

Перенеси пару на полный оборот

Меняй k. Оба угла сдвигаются на 2π за шаг; их синусы остаются равны 1/2.

k = 0: π/6 и 5π/6. В каждой точке sin x = 1/2.

Красная точка — первая серия, синяя — вторая; подписи перечисляют их в том же порядке. Ось на телефоне можно прокрутить.

При k = −1 получаем −11π/6 и −7π/6. Отрицательные углы тоже решения. Запись с k заменяет бесконечный список, но сама по себе не отбирает корни на заданном промежутке.

Для вас

Спросите, почему прибавляем именно 2π. Затем предложите назвать два отрицательных решения и проверить их положение на окружности.

Можно закончить первое короткое занятие после знакомства с формулами ниже.

Шаг 3 · короткая запись наблюдений

От рисунка к общему ответу

Для нетабличного a нужна запись одного исходного угла. arcsin a — угол из [−π/2; π/2], синус которого равен a. arccos a — угол из [0; π], косинус которого равен a. Они определены только при −1 ≤ a ≤ 1. Это названия обратных функций, а не обратных дробей: arcsin a не равно 1/sin a.

Синус: две точки на одной высоте

Пусть α = arcsin a. Вторая серия начинается с π − α; если угол получился вне первого оборота, полный оборот перенесёт его в нужный диапазон.

sin x = a:   x = α + 2πk   или   x = π − α + 2πk−1 ≤ a ≤ 1; α = arcsin a; k ∈ ℤ. При |a| > 1 действительных решений нет.

Косинус: отражение относительно горизонтальной оси

У точек с углами β и −β одна горизонтальная координата. Пусть β = arccos a:

cos x = a:   x = ±β + 2πkЭто две серии: β + 2πk и −β + 2πk, где −1 ≤ a ≤ 1 и k ∈ ℤ. При |a| > 1 действительных решений нет.

Особые значения: не считать одну точку дважды

Короткие ответы, k ∈ ℤ
УравнениеВсе решения

sin x = 1x = π/2 + 2πk
sin x = −1x = −π/2 + 2πk

При a = ±1 две общие серии sin или cos описывают одни и те же углы. При a = 0 две серии можно объединить в одну с шагом π.

Тангенс и котангенс: достаточно половины оборота

У противоположных точек оба знака координат меняются, а их отношение сохраняется. Поэтому tg и ctg повторяются через π. Напомним: tg x = sin x / cos x, ctg x = cos x / sin x. Повторить смысл отношений.

arctg a — угол из (−π/2; π/2), тангенс которого равен a. arcctg a здесь выбираем из (0; π), его котангенс равен a. Оба определены при любом действительном a.

tg x = a:   x = arctg a + πkk ∈ ℤ. tg x не определён при x = π/2 + πn, n ∈ ℤ.
ctg x = a:   x = arcctg a + πkk ∈ ℤ. ctg x не определён при x = πn, n ∈ ℤ.

Например, tg x = 1 даёт x = π/4 + πk, а ctg x = 0 даёт x = π/2 + πk. Эти корни лежат в области определения. Делить уравнение на sin x или cos x без проверки нулей нельзя: можно потерять допустимые корни.

Для вас

Не требуйте запомнить всё сразу. Пусть ученица восстановит две серии по окружности и объяснит разницу периодов 2π и π.

Полезный вопрос: почему у sin x = 1 нет двух разных точек, хотя в общей формуле две серии?

Занятие 2 · шаг 4

Общий ответ — ещё не список на отрезке

Пусть нужны корни sin x = 1/2 на [0; 2π]. Это замкнутый отрезок: оба конца входят. Возьми каждую серию, найди подходящие целые k, затем объедини корни и убери повторы.

Для первой серии: 0 ≤ π/6 + 2πk ≤ 2π. После деления на 2π получаем −1/12 ≤ k ≤ 11/12, значит k = 0.

Для второй: 0 ≤ 5π/6 + 2πk ≤ 2π, то есть −5/12 ≤ k ≤ 7/12, снова k = 0. Ответ: π/6 и 5π/6. Концы 0 и 2π не подходят: их синус равен нулю.

Мастерская отбора

Выбери уравнение и отрезок. Сравни корни при включённых концах. Для cos x = 1 на [0; 2π] подходят оба конца: это разные числа, хотя точка окружности одна.

[0; 2π]: корни π/6; 5π/6. Всего: 2.

В обеих сериях подходит k = 0.

Если отрезок превратился в одну точку [0; 0], проверь именно её. Если после отбора ничего не осталось, ответ — «корней на этом отрезке нет»; это не означает, что исходное уравнение вообще не имеет решений.

Для вас

Попросите предсказать число корней до изменения отрезка. Особенно полезны cos x = 1 на [−2π; 2π] и tg x = 1 на [−π; π].

Проверьте словами: почему 0 и 2π — два корня, хотя на окружности это одно положение?

Шаг 5 · сначала угол целиком

Что делать с sin(2x)?

Уравнение sin(2x) = 1/2 спрашивает об угле 2x. Обозначь его t. Реши знакомое sin t = 1/2, затем вернись к x:

2x = π/6 + 2πk   или   2x = 5π/6 + 2πk
x = π/12 + πk   или   x = 5π/12 + πkДелим на 2 каждый член, включая 2πk. Везде k ∈ ℤ.

На [0; π] в каждой серии подходит k = 0. Получаем π/12 и 5π/12. Подстановка: 2 · π/12 = π/6, 2 · 5π/12 = 5π/6; у обоих углов синус 1/2.

Если внутри ещё и сдвиг, шаги те же. Для cos(x − π/3) = 1 сначала x − π/3 = 2πk, затем x = π/3 + 2πk. Для общего линейного угла bx + c при b ≠ 0 сначала решаем уравнение относительно этого угла, вычитаем c и делим всю серию на b. При b = 0 от x ничего не зависит: проверяем постоянное равенство и область определения.

Предсказание 2. Какая запись даёт все решения sin(2x) = 1/2?

Подсказка

В равенстве 2x = π/6 + 2πk подели на 2 всю правую часть.

Решение

Верна запись с πk, k ∈ ℤ. Вариант с 2πk теряет, например, x = 13π/12: тогда 2x = 13π/6 = π/6 + 2π и синус равен 1/2.

Для вас

Спросите, на каком шаге изменился период. Признак понимания: ученица делит обе части равенства и может показать потерянный корень в неверной записи.

Шаг 6 · попробуй самостоятельно

Найди все, проверь каждый

В задачах 1–7 введи коэффициенты при π через точку с запятой. Например, для корней −π/2 и 2π напиши −1/2; 2. Порядок не важен, повторы убираются. Знак π вводить не нужно. Дроби точные; десятичные ответы округляй минимум до трёх знаков (допуск 0,0005 для каждого коэффициента). Запятая и точка принимаются.

1. sin x = 1/2, x ∈ [0; 2π]. Введи коэффициенты при π.

Подсказка

Один угол 30°. Отрази точку относительно вертикальной оси.

Решение

x = π/6 или 5π/6. В обеих сериях подходит только k = 0. Ввод: 1/6; 5/6.

2. cos x = −1/2, x ∈ [0; 2π]. Введи коэффициенты при π.

Подсказка

arccos(−1/2) = 2π/3. У второй точки противоположный знак вертикальной координаты.

Решение

Общий ответ x = ±2π/3 + 2πk. На отрезке: 2π/3 и −2π/3 + 2π = 4π/3. Ввод: 2/3; 4/3.

3. sin x = 1, x ∈ [−2π; 2π]. Введи коэффициенты при π.

Подсказка

Используй одну серию π/2 + 2πk и проверь отрицательный k.

Решение

Подходят k = −1 и 0. Корни −3π/2 и π/2. Ввод: −3/2; 1/2. При k = 1 уже 5π/2 > 2π.

4. cos x = 1, x ∈ [0; 2π]. Введи коэффициенты при π.

Подсказка

Все корни — полные обороты. Не исключай правый конец.

Решение

x = 2πk; подходят k = 0 и 1. Ответ: 0 и 2π. Ввод: 0; 2.

5. tg x = 1, x ∈ [−π; π]. Введи коэффициенты при π.

Подсказка

x = π/4 + πk. Проверь k = −1 и k = 0.

Решение

Корни −3π/4 и π/4. Ввод: −3/4; 1/4. Их косинусы ненулевые, тангенс определён. ±π/2 не являются корнями: там tg не определён.

6. ctg x = 0, x ∈ [0; 2π]. Введи коэффициенты при π.

Подсказка

Нужны верхняя и нижняя точки окружности.

Решение

x = π/2 + πk. На отрезке получаем π/2 и 3π/2. Ввод: 1/2; 3/2. В точках 0, π, 2π котангенс не определён.

7. sin(2x) = 1/2, x ∈ [0; π]. Введи коэффициенты при π.

Подсказка

Угол 2x лежит в [0; 2π]. Какие два значения из задачи 1 ему подходят?

Решение

2x = π/6 или 5π/6 на нужном промежутке. Значит x = π/12 или 5π/12. Ввод: 1/12; 5/12.

8. Сколько действительных корней имеет sin x = 1,5? Введи одно целое число — количество корней.

Подсказка

Может ли вертикальная координата на окружности радиуса 1 быть больше 1?

Решение

Нет: −1 ≤ sin x ≤ 1. Корней нет, их количество 0. Ввод: 0. Не путай отсутствие корней с корнем x = 0: sin 0 = 0, а не 1,5.

Объясни без подсказки

Почему один arcsin не даёт все решения? Почему tg повторяется через π, а sin — через 2π? Как проверить, что на отрезке не потерян конец? Если можешь ответить своими словами и решить похожий пример, двигайся дальше.

Для вас

Не обязательно решать всё за один раз. После ошибки предложите рисунок или подстановку; решение открывайте после собственной попытки.

Сравните задачи 1 и 3: число точек за оборот зависит от уровня. Сравните 1 и 4: включённый конец не всегда корень.

Можно вернуться сюда

Шпаргалка: угол → серии → отбор

  1. Проверь, возможно ли значение функции. Для sin/cos нужно |a| ≤ 1; для tg/ctg помни область определения.
  2. Найди исходные углы на окружности: одинаковая высота для sin, одинаковая горизонтальная координата для cos.
  3. Добавь полные периоды. У sin/cos обычно две серии с 2πk; у tg/ctg одна с πk. Особые случаи могут объединять серии.
  4. Если вместо x выражение, реши относительно x, преобразуя каждый член, включая период.
  5. Отбери целые k по каждому ряду, проверь концы промежутка, удали повторы и подставь корни в исходное уравнение.
