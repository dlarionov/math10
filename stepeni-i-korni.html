Степени
и корни

У квадрата площадь 9. Почему сторона равна 3, хотя и (−3)² = 9? Разберись, что возвращает корень и как он связан с дробной степенью.

Занятие 1 · шаг 1

Вернуться от площади к стороне

Квадрат со стороной 3 имеет площадь 3 · 3 = 9. Если известна площадь, нужно выполнить обратное действие: найти неотрицательное число, квадрат которого равен 9. Это число называют арифметическим квадратным корнем из 9 и записывают √9.

√9 = 3, а не ±3.

Число −3 тоже даёт 9 при возведении в квадрат. Поэтому уравнение x² = 9 имеет два решения: x = 3 и x = −3. Но знак √ выбирает только неотрицательное значение. Длина стороны тоже неотрицательна.

Что вспомнить о степенях

a³ = a · a · a. При a ≠ 0: a⁰ = 1 и a−k = 1/ak, где k — положительное целое. Отрицательный показатель переворачивает дробь, а не меняет знак: 2−3 = 1/8.

Ноль в положительной целой степени равен нулю. 0⁰ здесь не определяем; отрицательная степень нуля не определена из-за деления на ноль.

Скобки важны: (−3)² = 9, а −3² = −(3²) = −9.

Для вас

Попросите объяснить разницу между «вычислить √9» и «решить x² = 9». Не считайте запись ±3 верным значением арифметического корня.

Шаг 2 · исследование

Квадрат теряет знак

Числа 4 и −4 имеют одинаковый квадрат 16. По одному квадрату нельзя узнать исходный знак. Корень возвращает неотрицательное число — расстояние от x до нуля. Это расстояние называется модулем и обозначается |x|.

|x| = x при x ≥ 0; |x| = −x при x < 0.
√(x²) = |x| для любого действительного x.

Пройди через ноль

До движения предскажи: где окажется √(x²), если x = −4? Затем проверь ползунком.

Синяя точка — исходное x; красная — √(x²). Подписи различают точки и при совпадении.

x = −4; x² = 16; √(x²) = 4 = |x|. При отрицательном x корень не равен x.

Проверь x = 0 и x = 4. Когда x ≥ 0, точки совпадают. Когда x < 0, точка отражается относительно нуля. Ни в одном случае значение корня не становится отрицательным.

Разобранный пример

√(9x²) = √9 · √(x²) = 3|x|. При x = −2 это 6. Если написать 3x, получится −6 — отрицательное значение арифметического корня, значит, преобразование ошибочно.

Для вас

Спросите: «Почему модуль отрицательного x равен −x?» Здесь −x положителен: при x = −4 получаем −(−4) = 4.

Признак понимания: ученица сама проверяет формулу на отрицательном числе.

Шаг 3 · чётность

Не каждый корень ведёт себя как квадратный

Корень n-й степени из a — число, которое при возведении в натуральную степень n даёт a; здесь n ≥ 2. Маленькое n пишут у знака корня: n√a. Для квадратного корня двойку обычно опускают.

Арифметический корень n-й степени из a ≥ 0 — неотрицательное число, n-я степень которого равна a. При чётном n запись со знаком корня обозначает именно арифметический корень: она определена только при a ≥ 0. Например, уравнение x⁴ = 16 имеет два действительных корня −2 и 2, но ⁴√16 = 2. Ведь любая чётная степень неотрицательна. При нечётном n корень существует для любого действительного a и имеет тот же знак, что a: куб отрицательного числа отрицателен.

√16 = 4; ⁴√16 = 2; √0 = 0.
∛(−8) = −2, потому что (−2)³ = −8.
√(−9) не существует в действительных числах.

Нечётная степень сохраняет знак и строго возрастает, поэтому её обратное действие возвращает исходное число: ∛(x³) = x. Для чётной степени знак теряется: ⁴√(x⁴) = |x|.

Предскажи. Какая пара равенств верна?

Подсказка

Квадратный корень выбирает неотрицательное число; для кубического проверь куб ответа.

Решение

√16 = 4, потому что 4 ≥ 0 и 4² = 16. ∛(−8) = −2, потому что (−2)³ = −8. Верна вторая пара.

Для вас

Здесь можно закончить первое занятие. Перед продолжением попросите сравнить √((−2)²) и ∛((−2)³), объяснив знаки.

Занятие 2 · шаг 4

Показатель 1/n — обратный шаг

Хотим сохранить правило: при возведении степени в степень показатели перемножаются. Если возвести a1/2 в квадрат, показатель станет (1/2) · 2 = 1. Значит, результат должен быть a. При a > 0 выбираем положительное значение — √a.

Число, записанное дробью целых чисел с ненулевым знаменателем, называют рациональным. По той же идее для положительного основания a, целого m и натурального n ≥ 2 определяем:

am/n = (n√a)m = n√(am), a > 0.

Знаменатель n указывает корень, числитель m — целую степень. Равные дроби дают одинаковый результат: 161/2 = 162/4 = 4. Если m отрицателен, после извлечения корня берём обратную степень.

Два точных вычисления

163/4 = (⁴√16)³ = 2³ = 8.
27−2/3 = (∛27)−2 = 3−2 = 1/9.

Мастерская дробной степени

До изменения m с 2 на −2 предскажи, что произойдёт с результатом при a = 9, n = 2.

a = 9; m/n = 2/2. Корень второй степени из 9 равен 3; 3² = 9.

Числа в мастерской округляются до 0,001; знак ≈ указывает приближение, в том числе для целых результатов. Обратная проверка иллюстрирует вычисление и не заменяет определение.

Ноль и отрицательное основание

При положительном рациональном r полагаем 0r = 0. При r < 0 пришлось бы делить на ноль; при r = 0 получаем 0⁰, которое в этом уроке не определено.

Для отрицательного основания целые степени определены, а явно записанные нечётные корни могут быть отрицательными: ∛(−8) = −2. Но формулы рациональной степени этого урока применяй при a > 0. Не подставляй отрицательное основание в них автоматически.

Почему нужна осторожность? Дроби 1/3 и 2/6 равны. Однако ∛(−8) = −2, а ⁶√((−8)²) = 2. Механическая замена записи приводит к разным знакам. Для отрицательных оснований сначала уточняй определение; здесь используй запись через корни и целые степени.

Для вас

Попросите объяснить 163/4 словами: «четвёртый корень, затем куб». При отрицательном показателе важно услышать «обратное число», а не «отрицательное число».

Шаг 5 · сначала условия

Правила работают на своей территории

Для положительных a, b и рациональных r, s сохраняются знакомые свойства:

ar · as = ar+s; ar / as = ar−s;
(ar)s = ars; (ab)r = arbr.a > 0, b > 0; r и s — рациональные числа. Рациональное число можно записать дробью целых чисел с ненулевым знаменателем.

Например, √a · √a = a1/2 + 1/2 = a. В общем случае дроби показателей можно привести к общему знаменателю: выражения становятся целыми степенями одного положительного корня, и работают правила целых степеней.

Отдельно для квадратных корней:

√(ab) = √a · √b при a ≥ 0, b ≥ 0;
√(a/b) = √a / √b при a ≥ 0, b > 0.

Объяснение первого правила: справа неотрицательное число, квадрат которого равен ab, значит, это √(ab). Для частного рассуждение такое же, но знаменатель должен быть ненулевым.

Упростить и проверить

√72 = √(36 · 2) = 6√2. Оба множителя неотрицательны.
√(x − 2) существует при x − 2 ≥ 0, то есть x ≥ 2.
1/√(x − 2) требует уже x > 2: корень в знаменателе не может быть нулём.

Две ловушки

√(9 + 16) = 5, а √9 + √16 = 7. Корень суммы нельзя разносить по слагаемым.

√((−2)(−8)) = √16 = 4 существует. Но √(−2) · √(−8) в действительных числах не определено. Положительного произведения недостаточно для раздельного извлечения корней.

Для вас

Перед преобразованием спросите: «Существуют ли обе части?» Один контрпример опровергает неверное общее правило, а несколько совпавших примеров ещё не доказывают его.

Шаг 6 · самостоятельная практика

Проверь смысл и знаки

Реши на бумаге, затем проверь. Можно пользоваться подсказками и открывать решения в любом порядке.

1. Вычисли √((−5)²).

Подсказка

Сначала возведи −5 в квадрат.

Решение

(−5)² = 25, √25 = 5. Это |−5|, а не −5.

2. Реши x² = 25.

Подсказка

Проверь и положительное, и отрицательное число.

Решение

5² = 25 и (−5)² = 25. Решения x = ±5; значение √25 при этом равно только 5.

3. Вычисли ∛(−64).

Подсказка

Какое число в кубе даёт −64?

Решение

(−4)³ = −64, поэтому ∛(−64) = −4.

4. Вычисли 163/4.

Подсказка

Сначала найди четвёртый корень из 16.

Решение

⁴√16 = 2; 2³ = 8. Основание положительно, правило применимо.

5. Вычисли 27−2/3.

Подсказка

Извлеки кубический корень, возведи в квадрат и возьми обратное число.

Решение

∛27 = 3; 3² = 9, поэтому 27−2/3 = 1/9.

6. Упрости √(9x²) для любого действительного x.

Подсказка

√(x²) = |x|.

Решение

Оба множителя 9 и x² неотрицательны. √(9x²) = 3|x|. При x = −2 получаем 6, поэтому 3x не подходит.

7. При каких x существует √(x − 2) в действительных числах?

Подсказка

Реши неравенство x − 2 ≥ 0.

Решение

Нужно x − 2 ≥ 0, значит, x ≥ 2. Граница включена: при x = 2 корень равен нулю.

8. Чему равно 0−1/2?

Подсказка

Попробуй записать 1/√0.

Решение

Получилось бы 1/0. Деление на ноль не определено; ответ не является ни нулём, ни бесконечностью.

Вводи число или дробь. При округлении до 0,001 допускается погрешность не более 0,0005. Можно использовать запятую или точку. Выражения с корнями и степенями в поле не вводятся.

Для вас

Попросите назвать условие применения правила до вычисления. Если ответ неверен, отдельно обсудите выбор знака, допустимость действия и арифметику.

Шпаргалка

Сначала существование, потом вычисление

√(x²) = |x|; ∛(x³) = x.
am/n = (n√a)m при a > 0.
a−r = 1/ar при a > 0.

Чётный корень: подкоренное выражение ≥ 0, результат ≥ 0. Нечётный корень: любое действительное подкоренное выражение, знак сохраняется. Корень в знаменателе дополнительно не равен нулю.

Проверь себя словами: почему √9 не равно ±3? Что возвращает √(x²) при отрицательном x? Почему 0−1/2 не определено? Как вычислить 27−2/3 без калькулятора?

Для связи с другими темами: преобразования графиков. В графике y = √x область определения x ≥ 0 — часть смысла функции.

Для вас

Признак понимания: ученица объясняет корень обратным действием, сама различает уравнение и значение выражения, проверяет ноль и отрицательный пример.
