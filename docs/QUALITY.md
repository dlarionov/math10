# Проверка качества

## Базовая проверка для всех изменений

```powershell
python3.12 scripts/check_project.py
git diff --check
python3.12 scripts/check_privacy.py --staged
```

Перед push дополнительно запускаем `python3.12 scripts/check_privacy.py --history main`. Проверяем author и committer всех доступных через main коммитов. Сканер ищет распространённые секреты и приватные сведения, но не гарантирует обнаружения произвольных данных. Не выводим найденные значения в отчёты.

Python-скрипт требует Python 3.9 или новее и не требует сторонних пакетов. Он проверяет обязательные файлы, UTF-8, локальные ссылки в Markdown и HTML, HTML-якоря, уникальность HTML-id, метаданные страниц, присутствие уроков в каталоге и реестре. Сетевые ссылки не запрашиваются. JavaScript, формулы, контраст и поведение браузера он не проверяет.

Документационные изменения обычно не требуют браузера. Для нового или изменённого интерактивного поведения используем следующую матрицу.

## Матрица нового урока

| Область | Что проверить | Свидетельство |
| --- | --- | --- |
| Математика | Формулы с условиями; независимые решения всех задач; знаки, ноль, границы | Примеры и результаты в спеке |
| Основной сценарий | Открытие с диска, навигация, все интерактивные блоки | Фактический браузерный запуск |
| Ввод | Верный и неверный ответ; пустой ввод; дробь; запятая и точка; недопустимая запись | Независимые ожидаемые значения |
| Диапазоны | Минимум, максимум, особые значения параметров | Включить в проверку интерактивных блоков |
| Телефон | Viewport 390 CSS px, без переполнения всей страницы | Проверка DOM и визуальный просмотр |
| Темы | Светлая и тёмная, подписи и различимость элементов | Визуальный просмотр |
| Клавиатура | Tab/Shift+Tab, Enter/Space, фокус после перерисовок | Ручной или автоматизированный сценарий |
| Без сети | Новая страница не требует внешних ресурсов | Осмотр ссылок и запуск offline |
| Без JS | Основной текст, формулы и сообщение об ограничениях доступны | Проверка отключённого JavaScript |
| Хранилище | Сохранение/восстановление; недоступный localStorage не ломает урок | Браузерный сценарий |
| Чистота | Нет ошибок JS и собственных временных файлов | Консоль/перехват ошибок и git status |

Не каждый урок содержит все виды ввода или хранилище. Неприменимые строки отмечаем как неприменимые, а не создаём функции ради проверок.

## Браузер на Windows

Можно использовать установленный Chrome или Edge в headless-режиме. Пример команды для снимка (каталог .artifacts предварительно создать):

```powershell
& 'C:/Program Files/Google/Chrome/Application/chrome.exe' --headless=new --disable-gpu --user-data-dir="$PWD/.artifacts/chrome-profile" --screenshot="$PWD/.artifacts/lesson.png" --window-size=1200,900 "file:///$($PWD.Path.Replace('\','/'))/binom-nyutona.html"
```

Путь и флаги подбираются под среду. Не меняйте личный профиль браузера. Ошибка запуска браузера — ограничение проверки, а не ошибка урока; сначала проверьте окружение.

Для телефона недостаточно маленького PNG: headless-браузер может ограничивать ширину окна. Задайте viewport через доступный инструмент эмуляции или Chrome DevTools Protocol и проверьте `window.innerWidth`. В предыдущей сессии работали Chrome и CDP с `Emulation.setDeviceMetricsOverride` на 390 × 844.

Во время проверки временные профили, DOM-дампы и снимки держите в .artifacts/ либо в явно обозначенных .qa-* файлах. После завершения задачи удаляйте собственные временные скрипты, снимки, дампы, профили и кеши, останавливайте все запущенные для проверки процессы, включая браузеры и серверы. Для следующей задачи запускайте их заново. Игнорирование файлов в Git не заменяет уборку. Останавливайте только свои процессы. Перед рекурсивным удалением проверяйте абсолютный путь внутри проекта.

## Как фиксировать результат

В конце спеки достаточно нескольких строк: дата, проверенная версия/изменение, команда или сценарий, результат, ограничения. Не нужно сохранять большие DOM-дампы и отчёты каждого прогона.

Исходные тригонометрические страницы ещё не прошли эту матрицу целиком. Прежние проверки бинома перечислены в его спеке; новые критерии не считаются автоматически закрытыми.
