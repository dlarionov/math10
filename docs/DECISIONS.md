# Журнал решений

Храним причины решений о продукте и разработке. Переписку и личные обстоятельства участников не публикуем.

## D001 · Самостоятельные HTML-уроки

Основной сценарий — открытие урока с диска. Сохраняем один HTML-файл на урок, без сборки, сервера и runtime-библиотек. Повторение небольшого CSS и вспомогательных функций допустимо до появления конкретной причины для общей инфраструктуры. Python нужен только для проверок разработчиком.

## D002 · Облегчённая SDD

Приняты конституция, один файл на существенную спеку, общий roadmap, журнал решений и одна текущая передача сессии. Не создаём обязательные многоступенчатые согласования и отдельные планы для мелких изменений. Старые уроки описаны как исходная база, а не как заново принятые реализации.

## D003 · Автономная работа с Git

Обычные коммиты и push в origin/main выполняются самостоятельно. Публикация сайта, платные сервисы и разрушительные операции требуют соответствующего задания. Переписывание истории допустимо при явно поставленной задаче очистки приватных данных, с проверкой ожидаемого состояния удалённой ветки.

## D004 · Публичный реестр материалов

LESSONS.md и каталог описывают готовность уроков. Индивидуальное прохождение и оценки не хранятся в публичном репозитории. Личные отметки могут сохраняться только в браузере пользователя.

## D005 · Передача между сессиями

На завершённых этапах обновляем docs/SESSION.md с техническим состоянием, ограничениями, следующим действием и стартовым запросом. Новую сессию предлагаем на границе самостоятельной работы, без прерывания текущей задачи.

## D006 · Публичная история и нейтральное авторство

Публикуем только сведения о продукте. Персональный контекст удаляем из текущих файлов и исходных снимков; исходные коммиты сохраняем по смыслу, заменяя author/committer нейтральной identity. Настройку применяем только локально в репозитории.

Подготовлена альтернативная история с нейтральным авторством. Для задачи 005 разрешена целевая замена main через точный force-with-lease после проверки удалённого hash. Содержательные исходные коммиты сохраняются, текущие изменения документов переносятся поверх очищенных снимков. Автоматический аудит проверяет файлы и историю, не раскрывая значения совпадений. Это разовое исключение; обычная дальнейшая работа использует fast-forward push.

## D007 · Концепции, опорные учебники и необязательное углубление

14 ноября 2026 года. Коллекция развивается вокруг самостоятельных математических идей. Класс — ориентир для сложности и предварительных знаний, не граница допустимого содержания и не обещание полного школьного курса. Конституция повышена до 1.2. Опорные линии Алимова и Атанасяна и доступные федеральные программы используются для [карты покрытия](COVERAGE.md), а не для объявления соответствия конкретному расписанию. Различия изданий и недоступные источники указаны рядом со сверкой.

Основной и углублённый маршруты планируются внутри одного урока, чтобы не дублировать страницу и не заставлять выбирать учебный профиль до знакомства с идеей. Углубление должно добавлять содержательный вопрос, иметь явные предварительные знания и оставаться необязательным. Раскрывающийся блок или переключатель, объём пилота и проверка доступности уточняются в отдельной реализации B02; существующие страницы этой задачей не изменяются.

## D008 · Тематический каталог для разных посетителей

14 ноября 2026 года. Основная навигация должна группировать уроки по концепциям, показывать необходимые знания и необязательные короткие маршруты. Хронологический список неудобен для выбора темы; новинки могут остаться дополнительным блоком. Проект каталога описан в [карте](COVERAGE.md), реализация отложена в B01 из [roadmap](ROADMAP.md).

В каталоге не вводятся личные отметки, аккаунты, история посещения и проценты выполнения. Готовность материалов остаётся характеристикой продукта в LESSONS.md. Это решение не является поручением удалять существующие локальные функции внутри прежних уроков.
