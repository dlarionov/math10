# Передача сессии

Этот файл хранит только техническое состояние публичного проекта. Личные сведения, переписку и индивидуальные результаты обучения сюда не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Подготовлено

- Каталог и три урока; состояние материалов — [LESSONS.md](../LESSONS.md).
- Облегчённый SDD, исходные спеки и следующая спека графиков.
- Статическая проверка проекта без сторонних пакетов.

## Следующая задача

Завершить [005 · Подготовка публичного репозитория](../specs/005-public-privacy.md): подготовленная очищенная история дополняется актуальными документами и отправляется в main. Для этой операции разрешён точный force-with-lease; ожидаемый удалённый hash сверяется до отправки.

Сохраняем оба исходных коммита по смыслу с нейтральными author/committer и очищенными историческими снимками. Новые изменения и новые авторы проверяются. После успешной отправки обновить статус спеки и эту передачу; серверные кеши и внешние копии не считать проверенными.

Реализовать [004 · Преобразования графиков](../specs/004-function-transformations.md), если эта тема выбрана следующей. Реализация ещё не начата. Альтернатива — вероятность и комбинаторика.

Стартовый запрос для новой сессии:

> Продолжаем math10. Прочитай AGENTS.md и docs/SESSION.md. Сделай урок по specs/004-function-transformations.md, проверь его и отправь изменения в репозиторий.

## Ограничения и проверка состояния

- Конкретный учебник и профиль не заданы; карта тем не повторяет утверждённый календарный план.
- В исходных тригонометрических страницах есть необязательные Google Fonts; при отсутствии сети работают запасные шрифты.
- Полная новая матрица качества для исходных уроков не выполнена. Результаты прежних проверок бинома описаны в его спеке.
- Для статических проверок нужен Python 3.9+; для интерактивных — доступный браузер.
- Состояние Git проверять через `git status -sb` и `git log -1`. Основная ветка main, remote origin.
- Коммиты и обычный push разрешены автономно. Перед отправкой проверять файлы и метаданные на приватные данные.
