## Завершённый этап

14 ноября 2026 года выполнена **B01 — тематический каталог**, [спека 016](../specs/016-thematic-catalog.md). Спека создана до изменения HTML. В [index.html](../index.html) все двенадцать уроков распределены по пяти разделам: числа и закономерности (2), функции и графики (3), тригонометрия (4), геометрия (2), случайность и данные (1).

У каждой карточки есть вопрос, необходимые знания и ссылка с отдельным доступным именем. Добавлены три необязательных маршрута и переход к основному содержимому. После небольшой редакционной доработки в каталоге нет Markdown-ссылок, служебных статусов, описания будущих тем и лишних пояснений. Статусы материалов остаются в LESSONS.md; учебные страницы не менялись. Отметок прохождения, процентов, аккаунтов и персональной истории нет. Каталог состоит из HTML/CSS, без JavaScript и хранилища.

Chrome/CDP: file:// offline, 1200 × 900 и 390 × 844, светлая и тёмная темы. Нет горизонтального переполнения. Просмотрены снимки вводного блока, карточек и маршрутов, отдельный геометрический раздел без JS. Реальные Tab/Shift+Tab/Enter проверили пропуск к main, все пять тем, маршруты, открытие урока с карточки и из маршрута, возврат из футера к main. Без JS работают все элементы; исключение при чтении localStorage не влияет на каталог. При отдельной загрузке каталога внешних запросов и ошибок JS не зарегистрировано.

В первоначальной приёмке независимо сверены списки страниц в разделах и маршрутах, вопросы, необходимые знания и тогдашние статусы из реестра. Дополнительно проверены два смысловых примера вопросов: ровно один орёл при двух независимых бросках честной монеты имеет вероятность 1/2; корень из квадрата −3 равен 3. После сокращения каталога выполнена новая проверка: двенадцать карточек, пять разделов и три маршрута; все ссылки ведут только на HTML и якоря. Chrome/file:// offline без JS, 1200 и 390 CSS px, обе темы — без переполнения и ошибок; Enter/Tab работают. Просмотрены новые снимки. Алгоритмы уроков не менялись.

Обновлены README, описание реестра, живая карта охвата, статус B01, D008 и индекс спецификаций. Предыдущая [спека 015](../specs/015-concept-map-and-backlog.md) сохраняет результат исследования, [карта концепций](COVERAGE.md) теперь описывает реализованный каталог. B02 — опция углубления внутри урока — пока не реализована, на карточках её наличие не обещается.

Для сокращённой редакции проверки прошли заново: `python3.12 scripts/check_project.py` — 42 документа, 13 HTML-страниц, 290 локальных ссылок; `git diff --check` — без ошибок. ## Следующее действие

Возможный следующий этап — **B02: необязательное углубление внутри одного урока**, сначала шаблон и один пилот. Перед изменением учебного кода нужна короткая спека 017. Выбрать содержательный пилот, например логарифмы или сечения; основной маршрут должен остаться понятным без дополнительных блоков. B02 и новые темы требуют отдельного поручения, автоматически очередь не реализовывать.

Это естественная граница для новой сессии; продолжить здесь тоже можно. Стартовый запрос при выборе B02:

> Продолжаем math10. Прочитай AGENTS.md, docs/SESSION.md, docs/COVERAGE.md и B02 в docs/ROADMAP.md. Подготовь спеку 017 и реализуй необязательное углубление внутри одного выбранного урока. Проверь оба маршрута и отправь изменения в репозиторий.

## Ограничения

- Каталог проверен в Chrome; другие движки не проверены. Markdown-карта и реестр доступны из документации проекта и не показаны в каталоге.
- Опорные линии — Алимов и Атанасян, не единый комплект всех московских школ. Источники и ограничения исследования сохранены в карте: базовая программа 2025 года, доступная углублённая редакция 2023; полные электронные учебники требуют входа. Соответствие актуальным требованиям всех программ не заявляется.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества и содержат необязательные Google Fonts; offline используются запасные шрифты. Локальные функции прежних уроков не удалялись. Это B03 из roadmap.
- Геометрические рисунки — проекции; ограничения урока о сечениях и результаты его проверок перечислены в [спеке 014](../specs/014-polyhedron-sections.md).
- Для тестового Chrome использовались --no-sandbox и отдельный временный профиль. Личные профили и настройки не менялись.
- Очистка истории 005 завершена ранее. Новая работа не разрешает force-push; серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены, нейтральная локальная Git identity — из AGENTS.md. При ограничении записи/сети использовать инструментальную эскалацию; при сообщении Git о владельце — разовый safe.directory только для проверенного текущего репозитория. Глобальные настройки не менять.
