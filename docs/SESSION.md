# Передача сессии

Здесь храним техническое состояние публичного проекта. Личные сведения и индивидуальные результаты обучения в Git не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Завершённый этап

Реализован урок [010 · Показательная функция](../specs/010-exponential-function.md): [страница урока](../pokazatelnaya-funkciya.html). От сравнения постоянной прибавки и множителя — к дробному/отрицательному времени, графику y = aˣ, действительному показателю, росту/убыванию и простым уравнениям/неравенствам. Два исследования, два предсказания, восемь задач с подсказками/решениями, шпаргалка и скрываемые заметки родителю. Ответы и настройки не сохраняются.

Chrome/CDP, file://, offline: по 13 349 автоматических проверок на 1200 и 390 CSS px, всего 26 702 с общими проверками. Проверены все 65 сочетаний q/t, 91 сочетание a/x, узлы кривой, границы окна, задания, ошибки ввода, числовой допуск и реальные события клавиатуры. Основной материал доступен без JS; блокировка localStorage не мешает работе. Исследования и практика просмотрены в обеих темах. Ошибок JS, внешних запросов и горизонтального переполнения страницы нет. Математические примеры сверены независимо через Fraction/Decimal; результаты и ограничения — в спеке 010.

Каталог, реестр, README, карта тем и индекс спек обновлены. Подготовлены девять уроков; точные статусы — в [LESSONS.md](../LESSONS.md). Проверки проекта, diff и приватности выполняются перед завершением. Работа сохраняется обычным коммитом и push; фактическую синхронизацию проверять через `git status -sb` и сравнение main с удалённой веткой.

## Ограничения

- Конкретный учебник и профиль не заданы: карта тем не является утверждённым календарным планом.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества, содержат необязательные Google Fonts; без сети используются запасные шрифты. Результаты прежних проверок — в соответствующих спеках.
- Новый урок использует непрерывную модель с постоянным множителем. Действительная степень объясняется через приближения без строгого построения. Основание a = 1 включено для сравнения и явно исключено из определения показательной функции. Фиксированное окно графика обрезает значения выше 9; подпись и стрелка сообщают о продолжении. Интерактивные числа округлены до 0,001, числовой допуск 0,0005. Символического решателя нет. Проверен Chrome, другие движки не проверены.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main. Глобальная конфигурация Git не меняется. Если Git сообщает о владельце каталога в инструментальной эскалации, использовать разовый `-c safe.directory=...` с проверенным путём текущего репозитория.
