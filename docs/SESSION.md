# Передача сессии

Здесь хранится только техническое состояние публичного проекта. Личные сведения и индивидуальные результаты обучения в Git не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Завершённый этап

Реализован урок [006 · Вероятность и комбинаторика](../specs/006-probability-combinatorics.md): [страница урока](../veroyatnost-i-kombinatorika.html), исходы монеты, роли и группы, сетка 36 пар кубиков, дополнение до единицы и независимость. Есть четыре интерактивных блока, два предсказания, восемь итоговых задач с подсказками/решениями, шпаргалка и заметки родителю. Ответы и настройки не сохраняются.

Chrome, file://, offline: по 192 автоматические проверки на ширине 1200 и 390 CSS px без ошибок; отдельно реальные клавиатурные события, отключённый JS и недоступный localStorage. Светлая/тёмная темы и телефон просмотрены визуально. Внешних запросов и ошибок JS нет. Контрольные ответы сверены независимым перебором Python. Подробности и ограничения — в спеке 006.

Каталог, реестр, индекс спек, README и карта тем обновлены. Подготовлены пять уроков; точные статусы материалов — в [LESSONS.md](../LESSONS.md). Работа сохраняется обычным коммитом и fast-forward push с аудитом приватности; фактическую синхронизацию проверять через git status -sb и git log -1.

## Следующее действие

Текущий урок завершён. Следующая предложенная тема — тригонометрические уравнения. Спеки и реализации ещё нет; автоматически тему не начинать. По запросу подготовить короткую спеку по [шаблону](../specs/TEMPLATE.md), затем реализовать и проверить. Для новой темы удобно начать отдельную сессию; продолжить текущую тоже можно.

## Ограничения

- Конкретный учебник и профиль не заданы: карта тем не является утверждённым календарным планом.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества, содержат необязательные Google Fonts; без сети используются запасные шрифты. Предыдущие проверки бинома — в его спеке.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main.
