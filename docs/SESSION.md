# Передача сессии

Здесь храним техническое состояние публичного проекта. Личные сведения и индивидуальные результаты обучения в Git не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Завершённый этап

Реализован урок [008 · Формулы сложения и двойного угла](../specs/008-angle-addition.md): [страница урока](../formuly-slozheniya.html). Вопрос «как найти sin 75° без калькулятора?» ведёт к повороту двух единичных направлений, формулам суммы/разности sin и cos, tg с условиями, двойному углу и трём формам cos 2α. Два исследования, два предсказания, восемь задач с подсказками/решениями, шпаргалка и скрываемые заметки родителю. Ответы и настройки не сохраняются.

Chrome/CDP, file://, offline: по 2724 автоматических проверки на 1200 и 390 CSS px. Проверены все 625 пар углов поворота, 25 положений двойного угла, задания, ошибки ввода, реальные клавиатурные события, отключённый JS и заблокированный localStorage. Рисунок, практика и двойной угол просмотрены в обеих темах. Ошибок JS и внешних запросов нет. Координаты сверены прямыми тригонометрическими функциями Python, ответы — также независимой рациональной арифметикой. Подробности и ограничения — в спеке 008.

Каталог, реестр, README, карта тем и индекс спек обновлены. Подготовлены семь уроков; точные статусы — в [LESSONS.md](../LESSONS.md). Статическая проверка: 28 документов, 8 HTML-страниц, 155 локальных ссылок. Работа сохраняется обычным коммитом и push с аудитом приватности; фактическую синхронизацию проверять через `git status -sb` и сравнение main с удалённой веткой.

Спеки и реализации ещё нет; автоматически тему не начинать. По запросу подготовить короткую спеку по [шаблону](../specs/TEMPLATE.md), затем реализовать и проверить. ## Ограничения

- Конкретный учебник и профиль не заданы: карта тем не является утверждённым календарным планом.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества, содержат необязательные Google Fonts; без сети используются запасные шрифты. Результаты прежних проверок — в соответствующих спеках.
- Новый урок использует фиксированные варианты точных ответов и безопасный числовой ввод; символического решателя нет. Проверен Chrome, другие браузерные движки не проверены.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main. Глобальная конфигурация Git не меняется.
