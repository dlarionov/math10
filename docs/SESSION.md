## Завершённый этап

14 ноября 2026 года подготовлен и проверен двенадцатый урок — [сечения многогранников](../secheniya-mnogogrannikov.html), [спека 014](../specs/014-polyhedron-sections.md). Спека написана до реализации. Есть определение сечения, мастерская четырёх направлений разреза куба, касания и отсутствие пересечения, построение треугольника по граням в четыре шага, центральный правильный шестиугольник и восемь задач о кубе и тетраэдре. У каждой задачи есть подсказка и решение. Обновлены каталог, реестр, README, карта тем и индекс спецификаций. Прежние уроки не изменялись.

Независимые точные вычисления проверили все 484 положения плоскости: совпали вершины, число сторон и общая грань для соседних точек контура. Отдельно проверены стороны и углы центрального шестиугольника, треугольник из середин трёх рёбер и ответы практики. Математические результаты не получались из ключей ответов страницы.

Chrome/CDP: file:// offline, 1200 и 390 CSS px в двух темах, без горизонтального переполнения и ошибок JS. Проверены все направления и граничные положения, крайние повороты, сброс, все шаги построения, верные/неверные ответы всех восьми задач и ошибки числового ввода. Реальные Tab/Shift+Tab, стрелки, Enter и Space; фокус после перерисовок сохраняется. Просмотрены снимки мастерской, узкого заголовка, пятиугольника, построения, задачи и версии без JS. Без JS доступны статичные рисунки, текст, подсказки и решения. Недоступность localStorage не ломает урок; сам новый урок ничего не сохраняет. Внешних запросов страницы нет.

Базовые проверки прошли: `python3.12 scripts/check_project.py` — 39 документов, 13 HTML-страниц; `git diff --check` — без ошибок. Staged-аудит приватности прошёл. Перед push выполняется `python3.12 scripts/check_privacy.py --history main`. Diff просмотрен вместе с аудитом. Фактический результат синхронизации проверять по Git после отправки; локальный коммит сам по себе не подтверждает push.

До редактирования рабочее дерево было чистым. Fetch origin выполнен с разовым safe.directory для текущего репозитория; новых удалённых коммитов не было. Для записи в Git используется доступная инструментальная эскалация. Глобальные настройки не меняются. Собственные временные файлы, снимки и профиль Chrome удалены, проверочный браузер завершён; отсутствие процесса и закрытие проверочного порта проверены.

Ранее завершена [ревизия школьной терминологии одиннадцати прежних уроков](../specs/013-school-terminology.md); её результаты сохраняются в спеке 013.

## Ограничения

- Конкретный учебник и профиль не заданы; соответствие календарному плану не утверждается.
- Новая мастерская содержит четыре семейства параллельных плоскостей, не произвольный редактор сечений. Рисунки — параллельные проекции: длины и углы на экране искажены, невидимые рёбра не удаляются. Проверен Chrome, другие движки не проверены.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества и содержат необязательные Google Fonts; offline работают запасные шрифты. Проверки нового урока не являются повторной приёмкой прежних страниц.
- Для проверочного Chrome использовались --no-sandbox и отдельный временный профиль. Пользовательские профили и настройки не менялись.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main. При сетевом ограничении использовать инструментальную эскалацию; при сообщении Git о владельце — разовый `-c safe.directory=...` с проверенным путём текущего репозитория.
