# Передача сессии

Здесь храним техническое состояние публичного проекта. Личные сведения и индивидуальные результаты обучения в Git не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Завершённый этап

Реализован урок [012 · Прямые и плоскости в пространстве](../specs/012-lines-planes.md): [страница урока](../pryamye-i-ploskosti.html). Два исследования на вращаемом кубе, три случая двух различных прямых, задание плоскости, взаимное расположение прямой и плоскости, двух плоскостей; признак параллельности прямой и плоскости. Два предсказания, восемь задач с подсказками и решениями, шпаргалка и скрываемые заметки родителю. Ответы и настройки не сохраняются.

Chrome/CDP, file:// offline, 1200 и 390 CSS px: 433 проверки пройдены. Все заданные геометрические случаи при четырёх ракурсах, варианты ответов, сброс ракурса и реальные клавиатурные события проверены; геометрия независимо сверена по координатам единичного куба. Снимки обоих исследований в обеих темах просмотрены; ошибок JS, внешних запросов и горизонтального переполнения нет. Без JS доступны основной текст, исходные рисунки, подсказки и решения. Заблокированный localStorage не мешает работе. Подробности и ограничения — в спеке 012.

В уроке о показательной функции явно сопоставлены y = aˣ и степенная y = xᵃ. Оба названия школьные; корректный заголовок сохранён. В AGENTS.md закреплено требование использовать школьную терминологию и объяснять новые понятия до использования. Каталог, реестр, README, карта тем и индекс спек обновлены. Теперь подготовлено одиннадцать уроков; статусы — в [LESSONS.md](../LESSONS.md).

Работа завершается обычным коммитом и push после проверок проекта, diff и приватности. Фактическую синхронизацию проверять через `git status -sb` и сравнение main с удалённой веткой.

После завершения задач обязательна уборка: временные снимки, скрипты, дампы, профили и кеши удалять, собственные тестовые браузеры и серверы останавливать. Для следующих задач запускать заново; игнорируемые файлы тоже не оставлять. Правило закреплено в AGENTS.md и QUALITY.md.

## Следующее действие

Следующая задача — ревизия **всех одиннадцати готовых уроков**, а не новая тема. До исправлений подготовить короткую спеку 013 по [шаблону](../specs/TEMPLATE.md). Проверить названия, определения, обозначения и формулировки по школьным источникам. Для каждого замечания различать ошибку термина, недостаток пояснения и непривычный, но корректный школьный термин. Проверять также необходимые предварительные знания и введение понятий до использования. Исправления сопровождать источником и подходящей проверкой; изменения интерактивности — фактическим браузерным запуском и независимыми математическими примерами.

Ревизия запланирована, ещё не выполнена. Сечения многогранников остаются в очереди после неё и автоматически не начинаются. Можно начать отдельную сессию или продолжить здесь.

Стартовый запрос:

> Продолжаем math10. Прочитай AGENTS.md и docs/SESSION.md. Подготовь короткую спеку ревизии терминологии и формулировок всех готовых уроков по школьным источникам, затем проведи ревизию, исправь подтверждённые проблемы, проверь и отправь изменения в репозиторий.

## Ограничения

- Конкретный учебник и профиль не заданы: карта тем и ревизия терминологии не подтверждают соответствие конкретному календарному плану.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества, содержат необязательные Google Fonts; без сети используются запасные шрифты. Результаты прежних проверок — в соответствующих спеках.
- Новый геометрический рисунок — схематическая проекция каркаса; невидимые линии не удаляются, грани показывают части бесконечных плоскостей. Проверен Chrome, другие движки не проверены. Углы, расстояния и сечения не входят в урок.
- Для Chrome в проверочной среде потребовался флаг --no-sandbox и отдельный временный профиль. Пользовательские профили и настройки не менялись; временные файлы в Git не входят.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main. Глобальная конфигурация Git не меняется. При сетевом ограничении использовать доступную инструментальную эскалацию; при сообщении Git о владельце — разовый `-c safe.directory=...` с проверенным путём текущего репозитория.
