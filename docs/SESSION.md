# Передача сессии

Здесь храним техническое состояние публичного проекта. Личные сведения и индивидуальные результаты обучения в Git не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Завершённый этап

Реализован урок [009 · Степени и корни](../specs/009-powers-roots.md): [страница урока](../stepeni-i-korni.html). От площади квадрата — к арифметическому корню, модулю, чётности корней, рациональному показателю и условиям преобразований. Исследование √(x²) = |x|, мастерская дробной степени, предсказание, восемь задач с подсказками/решениями, шпаргалка и скрываемые заметки родителю. Ответы и настройки не сохраняются.

Chrome/CDP, file://, offline: по 1182 автоматические проверки на 1200 и 390 CSS px, всего 2366 с общими проверками ошибок и сети. Проверены все 25 положений x, 476 сочетаний a/m/n, все задания, ошибки ввода, границы числового допуска и реальные события клавиатуры. Основной материал доступен без JS; блокировка localStorage не мешает работе. Исследования и практика просмотрены в обеих темах. Ошибок JS, внешних запросов и горизонтального переполнения страницы нет. Математические примеры сверены независимо в Python; результаты и ограничения — в спеке 009.

Каталог, реестр, README, карта тем и индекс спек обновлены. Подготовлены восемь уроков; точные статусы — в [LESSONS.md](../LESSONS.md). Проверки проекта, diff и приватности выполняются перед завершением. Работа сохраняется обычным коммитом и push; фактическую синхронизацию проверять через `git status -sb` и сравнение main с удалённой веткой.

## Следующее действие

Текущий урок завершён. Следующая предложенная тема — показательная функция и логарифмы: сколько удвоений нужно для заданного роста? Разумно разделить большую тему на самостоятельные уроки. Спеки и реализации следующей темы нет; автоматически её не начинать. По запросу подготовить короткую спеку по [шаблону](../specs/TEMPLATE.md), затем реализовать и проверить. Для новой темы удобно начать отдельную сессию; продолжить текущую тоже можно.

Стартовый запрос:

> Продолжаем math10. Прочитай AGENTS.md и docs/SESSION.md. Подготовь спеку следующего урока о показательной функции, затем реализуй урок, проверь и отправь изменения в репозиторий. Логарифмы оставь для отдельного продолжения.

## Ограничения

- Конкретный учебник и профиль не заданы: карта тем не является утверждённым календарным планом.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества, содержат необязательные Google Fonts; без сети используются запасные шрифты. Результаты прежних проверок — в соответствующих спеках.
- Новый урок рассматривает рациональные степени при положительном основании и отдельно ноль. Для отрицательных оснований объяснены целые степени и явно записанные нечётные корни; общие правила дробных степеней на них не переносятся. Мастерская округляет до 0,001; числовой ввод принимает числа и дроби с допуском 0,0005. Символического решателя нет. Проверен Chrome, другие браузерные движки не проверены.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main. Глобальная конфигурация Git не меняется. Если Git сообщает о владельце каталога в инструментальной эскалации, использовать разовый `-c safe.directory=...` с проверенным путём текущего репозитория.
