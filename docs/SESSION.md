# Передача сессии

Здесь хранится только техническое состояние публичного проекта. Личные сведения и индивидуальные результаты обучения в Git не записываем.

## Контекст проекта

math10 — самостоятельные интерактивные уроки математики для 10 класса. Язык русский, сначала смысл, затем формула. Инструкции — [AGENTS.md](../AGENTS.md), принципы — [конституция](CONSTITUTION.md), процесс — [WORKFLOW.md](WORKFLOW.md).

## Завершённый этап

Реализован урок [007 · Тригонометрические уравнения](../specs/007-trigonometric-equations.md): [страница урока](../trigonometricheskie-uravneniya.html). Содержание: единичная окружность и радианы, серии корней sin/cos/tg/ctg, обратные функции, особые значения, отбор на замкнутом отрезке и линейное выражение вместо угла. Три интерактивных блока, два предсказания, восемь задач с подсказками/решениями, шпаргалка и заметки родителю. Ответы и настройки не сохраняются.

Chrome/CDP, file://, offline: по 340 автоматических проверок на ширине 1200 и 390 CSS px без ошибок. Проверены реальные клавиатурные события, отключённый JS и недоступный localStorage. Светлая/тёмная темы, окружность и практика просмотрены визуально. Ошибок JS и внешних запросов нет. Контрольные ответы и 100 вариантов отбора сверены независимым Python-перебором с подстановкой тригонометрических значений. Подробности и ограничения — в спеке 007.

Каталог, реестр, индекс спек, README и карта тем обновлены. Подготовлены шесть уроков; точные статусы материалов — в [LESSONS.md](../LESSONS.md). В каталоге также уточнён статус ранее проверенного урока о преобразованиях графиков по реестру. Работа сохраняется обычным коммитом и fast-forward push с аудитом приватности; фактическую синхронизацию проверять через `git status -sb` и сравнение `main` с удалённой веткой.

## Следующее действие

Текущий урок завершён. Следующая предложенная тема — формулы сложения и двойного угла. Спеки и реализации ещё нет; автоматически тему не начинать. По запросу подготовить короткую спеку по [шаблону](../specs/TEMPLATE.md), затем реализовать и проверить. Для новой темы удобно начать отдельную сессию; продолжить текущую тоже можно.

## Ограничения

- Конкретный учебник и профиль не заданы: карта тем не является утверждённым календарным планом.
- Исходные тригонометрические страницы ещё не прошли полную новую матрицу качества, содержат необязательные Google Fonts; без сети используются запасные шрифты. Предыдущие проверки бинома — в его спеке.
- Мастерская нового урока отбирает корни для четырёх заданных уравнений; произвольного символьного решателя нет. Проверен Chrome, другие браузерные движки не проверены.
- Очистка истории 005 завершена ранее. Новая работа не даёт разрешения на force-push. Серверные кеши и сторонние копии отдельно не проверены.
- Основная ветка main, remote origin. Обычные коммиты и push разрешены автономно. Нейтральная author/committer identity — из AGENTS.md; перед коммитом аудит staged, перед push аудит всей истории main.
