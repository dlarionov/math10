Уравнения и условия преобразований

Равносильные преобразования

Ты выполняешь действие с обеими частями уравнения. Вычисления верны — но вдруг появился лишний ответ. Или исчез нужный. Как сохранить все корни и не добавить посторонних?

Два занятия по 20–25 минут. Первая остановка — после возведения в квадрат. Нужны действия со скобками и подстановка числа; основные понятия повторим.

x = −2
↓ квадрат
x² = 4
Откуда взялось 2?

1. Сохраняем ответы, а не внешний вид

Корень уравнения — число, при подстановке которого обе части определены и равны. Например, у x = −2 единственный корень −2. После возведения обеих частей в квадрат получается x² = 4: теперь подходят и −2, и 2.

Почему? Квадрат забывает знак: (−2)² = 2². Поэтому вернуться от квадрата к исходному числу однозначно нельзя.

Множество решений содержит все корни уравнения. Запись {−2; 2} означает два числа, а ∅ — отсутствие решений. Равносильные уравнения имеют одно и то же множество решений. Равносильное преобразование заменяет уравнение равносильным ему.

x + 3 = 5 ⇔ x = 2Знак ⇔ означает: переход верен в обе стороны. У обоих уравнений один и тот же корень 2.
x = −2 ⇒ x² = 4Знак ⇒ означает: каждый корень слева подходит справа. Обратное не гарантируется. Правое уравнение — следствие левого.

Число 2 — посторонний корень для исходного уравнения: оно появилось после преобразования и не удовлетворяет исходной записи. Если подходящее исходному уравнению число исчезло после шага, мы потеряли корень.

Для обсуждения

Попросите подставить оба числа в обе записи. Важно увидеть различие между «все прежние корни сохранились» и «множество корней не изменилось».

2. Что произошло с корнями?

Выбери действие и двигай числа a и b. Мы сравниваем две записанные строки как уравнения над действительными числами. В режиме деления вторая строка намеренно записана без условия x ≠ 0: исследуем, чем опасен такой шаг.

Мастерская преобразований

До: x = −2
После: x² = 4

До — синие кольца. После — красные точки. Под каждой прямой подписаны числа.

Корни до: {−2}. Корни после: {−2; 2}.

Добавились: {2}. Потерялись: ∅.

Возведение в квадрат сохранило прежний корень, но добавило посторонний. Нужна проверка в исходном уравнении.

Попробуй a = 0 при возведении в квадрат и при делении. При умножении сделай a = b. Числа на прямых могут совпасть — объяснение под ними поможет отличить совпадение от общего правила.

Спросите до движения

Какой корень сохранится? Какой может добавиться или исчезнуть? После изменения попросите объяснить результат подстановкой, а не цветом точки.

3. Когда можно поставить ⇔?

Главный вопрос: можно ли выполнить обратное действие при всех рассматриваемых значениях x? Сначала сохрани условия существования выражений, затем проверь обратимость шага.

  • Прибавить или вычесть одно и то же число можно: обратное действие возвращает уравнение. Так же можно прибавить одно и то же выражение, если оно определено при всех рассматриваемых значениях x.
  • Умножить или разделить на одно и то же ненулевое число можно: обратное действие существует. Например, 3x = 6 ⇔ x = 2. Умножение на ноль превращает любое числовое равенство в 0 = 0 и стирает информацию.
  • Умножить или разделить на выражение с x равносильно на той части допустимых значений, где выражение определено и не равно нулю. Его нули нужно рассмотреть отдельно.

Перенос слагаемого через знак равенства с изменением знака — это вычитание одного и того же слагаемого из обеих частей. Правило объясняется обратимым действием.

3x + 5 = 11 ⇔ 3x = 6 ⇔ x = 2.

Вычли 5, затем разделили на 3. Проверка: 3 · 2 + 5 = 11. Здесь ни один шаг не добавил и не потерял корней.

Полезная привычка

Вместо общего «так можно» спросите: «Как вернуться к предыдущей строке? При каких x обратное действие существует?»

4. Квадрат: кандидатов может стать больше

Арифметический квадратный корень √t — неотрицательное число, квадрат которого равен t. Он определён при t ≥ 0. Поэтому в уравнении с корнем важны и подкоренное выражение, и знак второй части.

Решим √(x + 2) = x

Исходная запись определена при x ≥ −2. Левая часть неотрицательна, поэтому у любого решения ещё и x ≥ 0.

√(x + 2) = x ⇒ x + 2 = x²
x² − x − 2 = 0 ⇔ (x − 2)(x + 1) = 0

Произведение равно нулю, когда хотя бы один множитель равен нулю. Кандидаты: 2 и −1.

Проверяем в исходном уравнении: при x = 2 получаем √4 = 2 — верно; при x = −1 получаем √1 = −1 — неверно. Ответ: 2. Число −1 проходит исходную область определения, но не подходит по знаку: одной ОДЗ здесь недостаточно.

Если заранее сохранить условие x ≥ 0, возведение в квадрат в этом примере обратимо: обе части неотрицательны, а равные квадраты неотрицательных чисел означают равенство самих чисел.

√(x + 2) = x ⇔ система условий:
x + 2 = x² и x ≥ 0Условие x ≥ 0 здесь также обеспечивает x + 2 ≥ 0. Для общего уравнения √f(x) = g(x) сохраняют определённость выражений, f(x) ≥ 0 и g(x) ≥ 0.

Проверка отбрасывает добавленные корни. Она не возвращает корни, потерянные на предыдущем шаге.

Первая остановка

Можно завершить занятие здесь. Попросите объяснить, почему −1 проходит ОДЗ, но не является корнем, и почему проверяют исходную запись.

5. Деление: не потеряй случай с нулём

В уравнении x(x − 3) = 0 есть два корня: 0 и 3. Если сразу «сократить x», получится x − 3 = 0 и останется только 3. Делить на x при x = 0 нельзя — именно этот случай мы и пропустили.

x(x − 3) = 0 ⇔ x = 0 или x − 3 = 0

Можно и разделить, но с разбором:

  1. При x = 0 исходное равенство верно: сохраняем корень 0.
  2. При x ≠ 0 делим на x и получаем x − 3 = 0, то есть x = 3. Условие x ≠ 0 выполнено.
  3. Объединяем ответы: {0; 3}.

Умножение на выражение опасно в другую сторону. Из x = 1 после умножения на x + 2 получается (x − 1)(x + 2) = 0. Старый корень 1 сохранился, но добавился −2: при нулевом множителе обе части стали нулём.

Если исходные части и множитель определены, умножение сохраняет прежние корни; нули множителя могут добавить новые. Если сам множитель не определён при части исходных корней, можно потерять и их. Всегда учитывай область определения.

Проверка не всесильна

Подстановка 3 подтвердит найденный корень, но не покажет, что забыли 0. Для полноты решения нужно объяснить сохранение всех случаев.

6. После сокращения запрет остаётся

Область допустимых значений (ОДЗ) уравнения — все значения переменной, при которых обе его части определены. Например, знаменатель дроби не может быть нулём. ОДЗ задаёт, где ищем корни; она сама не является ответом.

Решим x² − 1x − 1 = 2

Сначала x ≠ 1. Затем разложим числитель: x² − 1 = (x − 1)(x + 1). При x ≠ 1 можно сократить общий множитель.

x² − 1x − 1 = 2 ⇔ x + 1 = 2 при x ≠ 1

Из x + 1 = 2 получается 1, но это запрещённое исходной записью значение. Уравнение не имеет корней: ответ ∅.

Сокращённая формула x + 1 определена при x = 1, а исходная дробь — нет. Поэтому сокращение не отменяет прежний запрет.

В логарифмах действует тот же подход: аргумент должен быть положительным, основание — положительным и отличным от 1. Даже если после преобразования логарифм исчез, исходные условия сохраняются.

Перед окончательным ответом

  1. Где исходные выражения определены?
  2. Какой шаг может добавить корни? Где нужна проверка?
  3. Какой шаг может потерять корни? Разобраны ли нули делителя?
  4. Какие кандидаты подходят исходному уравнению?

Связь с графиком

У исходной дроби при x = 1 нет значения. Формула прямой после сокращения не «заполняет» эту точку исходной функции.

7. Проверь ход решения

Можно вводить число с точкой или запятой, либо простую дробь: например, 2,0 или 4/2. В задачах с выбором нажми на множество решений. У каждого задания есть подсказка и решение.

Проверено верно: 0 из 8.

1. Корень и знак

Найди единственный корень √(x + 2) = x.

Подсказка

После квадрата получатся кандидаты 2 и −1. Оба ли могут равняться арифметическому корню?

Решение

x + 2 = x² ⇒ (x − 2)(x + 1) = 0. При 2 исходное равенство √4 = 2 верно, при −1 равенство √1 = −1 неверно. Ответ: 2.

2. Что потеряли при делении?

Реши x(x − 3) = 0.

Подсказка

Подставь x = 0 до деления на x.

Решение

Произведение равно нулю при x = 0 или x − 3 = 0. Ответ: {0; 3}. Безусловное деление на x теряет 0.

3. Запрет после сокращения

Реши x² − 4x − 2 = 4.

Подсказка

x ≠ 2. Разложи x² − 4 на множители.

Решение

При x ≠ 2 сокращение даёт x + 2 = 4, откуда x = 2. Оно запрещено исходным знаменателем. Ответ: ∅.

4. Обратимые шаги

Реши 3x + 5 = 11.

Подсказка

Какое одинаковое действие сначала уберёт +5 из левой части?

Решение

3x = 6 ⇔ x = 2. Проверка: 3 · 2 + 5 = 11. Все шаги равносильны.

5. Найди посторонний корень

Из x = −3 получили x² = 9. Какое число добавилось?

Подсказка

Какие два числа имеют квадрат 9?

Решение

У x² = 9 корни −3 и 3. В исходной записи был только −3. Добавилось число 3.

6. Верный ответ — достаточно ли этого?

Для (x − 1)² = 0 предложили разделить на x − 1 и получить x − 1 = 0. Как правильно оценить этот шаг?

Подсказка

При единственном корне исходного уравнения чему равен делитель?

Решение

При x = 1 исходное равенство верно, а делитель равен нулю: делить нельзя. При x ≠ 1 деление даёт x − 1 = 0, но 1 не удовлетворяет условию x ≠ 1, так что в этой ветви корней нет. После объединения случаев ответ {1}. Голые записи имеют одинаковый корень, но предложенное обоснование делением недопустимо.

7. Может ли эта дробь быть нулём?

Реши 1x − 2 = 0.

Подсказка

При x ≠ 2 умножение обеих частей на x − 2 допустимо. Что получится?

Решение

ОДЗ: x ≠ 2. Умножаем на x − 2 и получаем 1 = 0. Это невозможно. Ответ: ∅; x = 2 не допускается исходной дробью.

8. Самостоятельно от начала до конца

Найди единственный корень √(x + 6) = x.

Подсказка

x² − x − 6 = (x − 3)(x + 2). Что нужно проверить после решения квадратного уравнения?

Решение

ОДЗ: x ≥ −6, у корня правая часть также должна быть неотрицательной. После квадрата x + 6 = x² ⇒ (x − 3)(x + 2) = 0. При 3: √9 = 3, верно. При −2: √4 = −2, неверно. Ответ: 3.

Признак понимания

Учащийся объясняет, где мог появиться лишний корень, где мог исчезнуть нужный, и почему одной итоговой подстановки недостаточно для доказательства полноты решения.

8. Где эта привычка пригодится?

Степени и корни: равенство √(x²) = |x| объясняет, почему квадрат скрывает знак и почему нужны условия.

Логарифмы: исходные ограничения на аргументы сохраняются после применения свойств логарифмов.

Преобразования графиков: корни уравнения f(x) = g(x) — абсциссы общих точек графиков. Изменение выражений может изменить и эти точки.

Чтобы решить уравнение, мало получить какое-то подходящее число. Нужно обосновать, что найдены все и только его корни.
