Бином Ньютона

Как раскрыть (a + b)10, не перемножая десять скобок? Научимся считать одинаковые слагаемые — и увидим, почему та же идея помогает выбирать команду и считать шансы.

Нужно уметь: раскрывать скобки, умножать степени с одинаковым основанием, сокращать дроби.

Занятие 1 · шаг 1

В каждой скобке — один выбор

Бином — это сумма двух слагаемых, например a + b. Его квадрат ты уже знаешь. Но откуда в середине берётся двойка?

(a + b)2 = (a + b)(a + b) = aa + ab + ba + bb = a2 + 2ab + b2

Чтобы получить одно произведение, выбираем по одной букве из каждой скобки. Произведения ab и ba равны: порядок множителей не меняет результат. Поэтому их можно сложить.

Для куба есть восемь выборов: aaa, aab, aba, baa, abb, bab, bba, bbb. Три из них дают a²b, ещё три — ab².

(a + b)3 = a3 + 3a2b + 3ab2 + b3

Собери одно произведение

Выбирай a или b в каждой скобке. Ниже подсвечены все выборы с тем же количеством букв b.

Главный вопрос урока: сколько есть способов выбрать ровно k скобок, из которых мы возьмём b? Именно столько раз появится an−kbk.

В (a + b)³ сколько выборов дают a²b?

Для вас

Начните с вопроса: «Верно ли, что (a + b)² = a² + b²?» Подставьте a = b = 1: слева 4, справа 2.

Предложите учащимся самостоятельно выписать восемь выборов для куба. Цель — увидеть повторяющиеся произведения, прежде чем вводить новую формулу.

Не обязательно проходить весь материал за один раз. Первые три шага — отдельное занятие.

Шаг 2 · как считать выборы

Факториал и сочетания

Из пяти человек выбирают двоих в команду. Сначала можно выбрать одного пятью способами, затем второго — четырьмя. Получается 5 · 4 = 20. Но пара «Аня, Маша» и пара «Маша, Аня» — одна команда. Каждую пару посчитали дважды, поэтому ответ 10.

А если выбираем троих? Каждая тройка появится 3 · 2 · 1 = 6 раз: столько существует порядков для трёх разных человек. Такое произведение обозначают 3! и читают «три факториал».

n! = 1 · 2 · … · n при n ≥ 1;   0! = 1
3! = 6,   4! = 24,   5! = 120

Почему 0! = 1? Расставить ноль предметов можно одним способом: оставить пустую последовательность. Это также сохраняет правило 1! = 1 · 0!.

Сочетание — выбор k предметов из n разных предметов, в котором порядок не важен. Обозначения Cnk и «n над k» означают одно и то же число.

Cnk = n!k!(n − k)!,   0 ≤ k ≤ n
n и k — целые неотрицательные числа.

В числителе n!/(n − k)! считает последовательный выбор k предметов. Делим на k!, потому что перестановки выбранных предметов дают одну и ту же группу.

C52 = 5!/(2! · 3!) = (5 · 4)/(2 · 1) = 10.

Не вычисляй большие факториалы целиком: сначала сокращай общие множители.

Выбери команду

Отметь любых троих из пяти. Посмотри, какое сочетание получилось.

Всего C₅³ = 10 команд. Выбрать троих — то же самое, что выбрать двоих, которые останутся: C₅³ = C₅².

Когда порядок важен?

Выбрать капитана и заместителя из пяти человек: 5 · 4 = 20 способов. Здесь роли различаются, поэтому на 2! делить нельзя. Такой упорядоченный выбор без повторений называют размещением: Ank = n!/(n − k)!.

Расставить все n разных предметов по порядку — перестановка; способов n!.

Сколькими способами можно выбрать двоих из шести человек без распределения ролей?

Для вас

Проверьте понимание вопросом: «Почему мы делим на 2, а не вычитаем 2?»

Для бинома выбираются позиции скобок. Они различаются, хотя все буквы b одинаковые.

Обозначения C могут выглядеть иначе в школьном учебнике. Здесь n внизу — всего предметов; k вверху — сколько выбираем.

Шаг 3 · считаем без факториалов

Треугольник Паскаля

По краям стоят единицы. Каждое внутреннее число — сумма двух чисел над ним. Строки нумеруем с нуля: строка n содержит коэффициенты для (a + b)n.

Нажми на число: оно выделится, а два его «родителя» получат красную рамку.

Например: 6 = 3 + 3, строка n = 4, позиция k = 2.

Почему это работает? Представь, что из n человек выбирают k. Один человек — ты. Команды делятся на два случая: без тебя (из остальных выбирают k) и с тобой (из остальных выбирают k − 1).

Cnk = Cn−1k + Cn−1k−1   при 1 ≤ k ≤ n − 1
  • Cn0 = Cnn = 1: ничего не выбрать или выбрать всё можно одним способом.
  • Cnk = Cnn−k: выбрать участников — всё равно что выбрать тех, кто останется.
  • Сумма строки n равна 2n: для каждого из n предметов есть два решения — взять или оставить.

Найди средний коэффициент строки n = 6, то есть C₆³.

Для вас

Завершите первое занятие: закройте страницу и попросите построить строки n = 4 и n = 5 в тетради.

Вопрос на понимание: «Почему сумма строки n = 3 равна восьми?» Хороший ответ связывает это с восемью выборами букв из первого шага.

Занятие 2 · шаг 4

Собираем бином Ньютона

Теперь всё готово. В произведении n скобок выбираем k позиций для b; остальные n − k позиций дают a. Получаем Cnk одинаковых произведений an−kbk.

(a + b)n = ∑k=0n Cnkan−kbk

Знак ∑ означает «сложи»: подставь k = 0, затем 1 и так до n. Здесь n — целое неотрицательное число; при n = 0 получаем 1. Нулевая степень в этой формальной записи обозначает отсутствие соответствующего множителя.

(a + b)4 = a4 + 4a3b + 6a2b2 + 4ab3 + b4

У каждого слагаемого сумма показателей a и b равна n. Степень a убывает от n до 0, степень b растёт от 0 до n. Всего n + 1 слагаемое.

Мастерская разложений

При n = 0 результат равен 1. Мастерская показывает точные целые коэффициенты.

Как найти только нужный член

Не обязательно раскрывать всё. Член с индексом k имеет порядковый номер k + 1, ведь считаем k с нуля:

Tk+1 = Cnkan−kbk

Коэффициент при x³ в (2x − 1)⁵. Подставляем a = 2x, b = −1. Степень x равна 5 − k, значит 5 − k = 3 и k = 2.

T₃ = C₅² · (2x)³ · (−1)² = 10 · 8x³ · 1 = 80x³. Коэффициент — число 80.

Что меняет минус

В (a − b)n заменяем второе слагаемое на −b. Тогда появляется множитель (−1)k: при чётном k знак плюс, при нечётном — минус.

(a − b)3 = a3 − 3a2b + 3ab2 − b3

Чётная степень всей скобки не делает все её коэффициенты положительными. Например, (a − b)² = a² − 2ab + b².

Какой коэффициент стоит при x³ в (2x − 5)⁴?

Для вас

Перед началом попросите восстановить строку 1, 4, 6, 4, 1. Затем предложите расставить степени букв.

Самые частые ошибки: забыть степень числа 2 в (2x)³; взять k = 3 автоматически для x³; спутать индекс k и номер члена.

Бином применяем ко всему слагаемому: если a = 2x, возводим в степень и 2, и x.

Шаг 5 · связь с вероятностью

При чём здесь монетка?

Бросим честную монету три раза независимо. Есть 2³ = 8 равновероятных последовательностей. Ровно два орла появляются в трёх случаях: ООР, ОРО, РОО. Выбираем два места для орлов — это C₃².

P(ровно 2 орла из 3) = C₃²2³ = 38 = 0,375

Если вероятность успеха в одном испытании равна p, а неудачи — 1 − p, то конкретная последовательность с k успехами имеет вероятность pk(1 − p)n−k. Таких последовательностей Cnk.

P(ровно k успехов) = Cnkpk(1 − p)n−k

Формула работает, когда число испытаний фиксировано, испытания независимы, у каждого два исхода, а вероятность p одинакова. Выбор шаров из мешка без возвращения обычно этим условиям не отвечает.

Проверь на честной монете

Цветом выделено выбранное k. Полосы показывают вероятность; подписи округлены. Сумма точных вероятностей всегда 1.

Вся связь помещается в одну строку: (p + (1 − p))n = 1. Раскрывая скобки по биному, получаем вероятности всех возможных количеств успехов.

Какова вероятность ровно одного орла в трёх независимых бросках честной монеты? Введи дробь или десятичное число.

Для вас

Это дополнительный шаг, если основная идея уже понятна. Можно оставить на отдельный день.

Различайте «ровно два орла» и «хотя бы два». Во втором случае нужно сложить вероятности двух и трёх орлов.

Шаг 6 · попробуй самостоятельно

Проверка понимания

Сначала реши в тетради. Затем введи числовой ответ. Можно писать дроби, десятичную запятую или точку. У каждой задачи есть подсказка и решение.

1. Найди коэффициент при x в (x + 2)³.

2. Сколько слагаемых в стандартном разложении (a + b)⁵ до подстановки численных значений a и b?

3. Найди коэффициент при x³ в (x − 1)⁵.

4. Чему равна сумма коэффициентов многочлена (x + 1)⁶?

5. Чему равна сумма коэффициентов многочлена (x − 1)⁵?

6. Сколько разных команд из трёх человек можно составить из семи?

7. Какова вероятность хотя бы трёх орлов в четырёх независимых бросках честной монеты?

8. Какой показатель степени у a в четвёртом члене разложения (a + b)⁷, если идти от a⁷ к b⁷?

Как понять, что тема усвоена?

Ты можешь объяснить происхождение коэффициента, вычислить сочетание, раскрыть небольшую степень и найти отдельный член с учётом знака. Если ошибка только в вероятности, повтори шаг 5. Если путаются коэффициенты и степени, вернись к выбору букв в шаге 1.

Для вас

Ответы проверяются сразу; подсказки и решения открываются отдельно. Счётчик учитывает решённые задачи этого блока.

Попросите объяснить одно решение вслух. Число правильных ответов помогает найти затруднение, но не заменяет объяснение.

Cnk = n! / (k!(n − k)!)
