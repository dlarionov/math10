Неравенства и метод интервалов

Произведение двух отрицательных чисел положительно. Значит, чтобы узнать, где (x + 2)(x − 1) > 0, не нужно вычислять произведение для каждого x. Достаточно понять, где множители одного знака.

Понадобятся числовая прямая, знаки при умножении и простые уравнения. Множества решений, ОДЗ и запись промежутков напомним внутри.

1. Найти целое множество

Решение неравенства — значение переменной, при котором получается верное сравнение. Решить неравенство — найти все такие значения. В отличие от многих уравнений, ответом часто становится целый промежуток чисел.

Например, x > 1 означает все числа правее 1, но не саму единицу. Строгие знаки > и < не допускают равенства; нестрогие ≥ и ≤ допускают его.

Как записывать ответ

(a; b) — интервал: a < x < b, концы исключены. [a; b] — отрезок: a ≤ x ≤ b, концы включены. Скобки можно сочетать: [a; b) включает a и исключает b.

(−∞; a) — открытый луч x < a. Бесконечность — не число и не конец, который можно включить: рядом с ∞ всегда круглая скобка. Знак ∪ объединяет части ответа. {a} означает одно число a, ∅ — решений нет, ℝ — все действительные числа.

Область допустимых значений (ОДЗ) — значения, при которых исходное выражение определено. У дроби знаменатель не может быть нулём. Запрещённое число не становится решением даже при нестрогом знаке.

Для вас

Попросите привести число из промежутка (−2; 1) и число вне него. Отдельно уточните, входят ли −2 и 1: это важнее механического выбора скобки.

2. Разделим прямую на интервалы

(x + 2)(x − 1) > 0

Первый множитель равен нулю при x = −2, второй — при x = 1. Отметь эти числа по возрастанию: они делят прямую на три интервала.

Знак каждого множителя на открытых интервалах
Выражение(−∞; −2)(−2; 1)(1; +∞)
x + 2−++
x − 1−−+
Произведение+−+

Проверим по одному числу: при −3 получаем (−1) · (−4) = 4 > 0; при 0 получаем 2 · (−1) = −2 < 0; при 2 получаем 4 · 1 = 4 > 0.

Почему одного пробного числа достаточно? Линейный множитель x − a отрицателен левее a и положителен правее a. Внутри интервала ни один множитель не проходит через свой ноль, поэтому его знак не меняется. Значит, знак произведения и дроби из таких множителей тоже сохраняется, пока знаменатель не обращается в ноль.

Нужен положительный результат: выбираем два внешних интервала. При −2 и 1 произведение равно нулю, а знак строгий — эти точки исключаем.

Ответ: (−∞; −2) ∪ (1; +∞).

Метод интервалов — способ решать такие неравенства по знакам выражения на промежутках, разделённых нулями числителя и знаменателя.

Для вас

Спросите, почему x = −3 — только проверка знака, а не единственное решение. Попросите объяснить каждый плюс и минус в таблице.

3. Мастерская знаков

Выбери произведение или дробь, перемести нули множителей и смени знак сравнения. Сначала предскажи ответ, затем сверь таблицу и прямую. Ползунки допускают совпадение a и b.

(x + 2)(x − 1) > 0

ОДЗ: все действительные числа.

Толстые участки — решения. Закрашенная точка входит в ответ, пустая — не входит. Крестик отмечает запрещённую точку знаменателя. Лучи продолжаются за пределы рисунка.

Знаки на открытых интервалах; точки проверяем отдельно
Выражение(−∞; −2)(−2; 1)(1; +∞)
x + 2−++
x − 1−−+
Всё выражение+−+

Ответ: (−∞; −2) ∪ (1; +∞).

Точки −2 и 1 дают ноль и при строгом сравнении не входят.

Три исследования: переключи > на ≥ и проследи только за границами. Затем выбери дробь — ноль знаменателя останется исключённым. Наконец совмести a и b: таблица не должна автоматически чередовать знаки.

Для вас

Можно закончить первую часть занятия после мастерской. Для продолжения попросите воспроизвести алгоритм словами и объяснить, почему нестрогий знак не разрешает деление на ноль.

4. Границы проверяют отдельно

Алгоритм

  1. Перенеси всё в одну часть, чтобы в другой был ноль. Запиши исходную ОДЗ. Разложи числитель и знаменатель на множители.
  2. Найди нули множителей и отметь различные точки по возрастанию. Нули знаменателя сразу запрети.
  3. Определи знак на каждом открытом интервале по знакам множителей или по пробному числу.
  4. Выбери интервалы с нужным знаком. Для ≥ и ≤ добавь допустимые нули выражения, даже если рядом нет подходящих интервалов. Запрещённые точки всегда исключи.
  5. Запиши объединение промежутков и при необходимости отдельных точек. Проверь границы и одно число из каждой части ответа.

У дроби свои запрещённые точки

x + 2x − 1 ≥ 0

При x = −2 числитель равен нулю, а знаменатель равен −3: дробь определена и равна нулю, точку включаем. При x = 1 знаменатель равен нулю: точку исключаем при любом знаке сравнения.

Ответ: (−∞; −2] ∪ (1; +∞).

Не умножай сразу на x − 1. Его знак зависит от x. Умножение на положительное число сохраняет знак неравенства, на отрицательное — меняет на противоположный. Например, −2 < 1, но после умножения на −1 получаем 2 > −1. Метод интервалов учитывает эти знаки.

Знак не обязан чередоваться

Если множитель (x − a) повторён дважды, получается квадрат (x − a)². Говорят, что a — корень кратности 2: он два раза встречается в разложении на линейные множители. По обе стороны от a квадрат положителен, в самой точке — ноль. Знак при переходе через такой корень не меняется. То же верно для любой чётной кратности; при нечётной кратности знак соответствующего множителя меняется.

Например, (x − 1)² > 0 даёт (−∞; 1) ∪ (1; +∞), а (x − 1)² ≤ 0 даёт только {1}. Поэтому одних знаков открытых интервалов для нестрогого неравенства недостаточно.

Сокращение сохраняет исходную ОДЗ

x − 1x − 1 > 0,   x ≠ 1

На своей ОДЗ дробь равна 1. Неравенство верно для всех допустимых x, но x = 1 остаётся запрещённым: ответ (−∞; 1) ∪ (1; +∞).

А у (x − 1)²x − 1 ≤ 0 после сокращения остаётся x − 1 ≤ 0 при x ≠ 1. Ответ — (−∞; 1), без единицы. Совпавший ноль числителя не отменяет запрет знаменателя.

Для вас

Попросите объяснить отдельную точку {1} без обращения к таблице. Затем сравните квадрат и сокращённую дробь: почему похожий ноль в одном случае входит, а в другом нет?

5. Твоя очередь

Выбирай множество целиком, с правильными скобками. Проверка доступна сразу; в подсказках — следующий шаг, в решениях — объяснение.

1. Два внешних интервала

Реши (x + 2)(x − 1) > 0.

Подсказка

Нужны одинаковые знаки множителей; нули не подходят.

Решение

Левее −2 оба множителя отрицательны, правее 1 оба положительны. Между ними знаки разные. При границах произведение равно нулю. Ответ: (−∞; −2) ∪ (1; +∞).

2. Нестрогий знак

Реши (x + 2)(x − 1) ≤ 0.

Подсказка

Возьми отрицательный участок и допустимые нули.

Решение

Произведение отрицательно между −2 и 1, равно нулю в обеих границах. Ограничений ОДЗ нет, поэтому ответ [−2; 1].

3. Ноль знаменателя

Реши x + 2x − 1 ≥ 0.

Подсказка

Дробь и произведение имеют одинаковое правило знаков, но разные запреты.

Решение

При x < −2 и x > 1 дробь положительна. В −2 она равна нулю, в 1 не определена. Ответ: (−∞; −2] ∪ (1; +∞).

4. Повторяющийся множитель

Реши (x − 1)² > 0.

Подсказка

Квадрат положителен при любом ненулевом основании.

Решение

Квадрат равен нулю только при x = 1, в остальных точках положителен. Ответ: (−∞; 1) ∪ (1; +∞). Знак через 1 не меняется.

5. А есть ли решения?

Реши (x + 1)² < 0.

Подсказка

Может ли квадрат действительного числа быть отрицательным?

Решение

Квадрат неотрицателен при любом x. При −1 он равен нулю, а не отрицательному числу. Ответ: ∅.

6. После сокращения

Реши x − 2x − 2 > 0.

Подсказка

Сначала запиши исходную ОДЗ.

Решение

ОДЗ: x ≠ 2. На ней дробь равна 1, а 1 > 0. Подходят все допустимые числа. Ответ: (−∞; 2) ∪ (2; +∞).

7. Дробная граница

У неравенства 2x − 3 < 0 ответ имеет вид (−∞; c). Найди c.

Подсказка

Реши 2x − 3 = 0. Деление на положительное число сохраняет знак.

Решение

2x < 3, значит x < 3/2 = 1,5. Граница c = 1,5 не входит: ответ (−∞; 1,5).

8. Минус перед произведением

Реши −(x − 1)(x + 2) > 0.

Подсказка

После умножения на −1 знак неравенства меняется.

Решение

Получаем (x − 1)(x + 2) < 0. Между −2 и 1 множители разных знаков; границы исключены. Ответ: (−2; 1).

Для вас

Обсуждайте причины выбора скобок. Если ответ неверный, предложите подставить число из спорного участка и отдельно каждую границу.

6. Сначала знак, затем границы

Нули числителя могут входить при нестрогом сравнении. Нули знаменателя не входят никогда.

Между отмеченными точками знак произведения и дроби из линейных множителей постоянен. При повторяющихся множителях не полагайся на автоматическое чередование плюса и минуса.

После сокращения сохрани исходную ОДЗ. При умножении на отрицательное число меняй знак неравенства.

В ответе могут быть интервалы, лучи, отрезок, отдельные точки, все действительные числа или пустое множество.

Проверь себя: почему (x − 1)² ≥ 0 верно для всех x, а (x − 1)² > 0 исключает 1? В первой записи ноль допускается, во второй — нет. Ни в одной из них не нужна смена знака через двойной корень.

Равносильные преобразования → — как сохранять множество решений и исходные ограничения. Здесь та же привычка нужна при сокращении дроби и умножении на выражение.

Преобразования графиков → — если выражение обозначить f(x), то f(x) > 0 выбирает участки графика выше оси x, f(x) < 0 — ниже. Нули и разрывы помогают разделить эти участки.

Признак понимания

Учащийся решает новый пример, объясняет постоянство знака между точками и включение каждой границы. Соседние уроки можно открыть отдельно; обязательного прохождения нет.
