# 010 · Показательная функция

Статус: Реализована

## Цель и контекст

Отличать постоянное прибавление от постоянного умножения; объяснять график y = a^x, ограничения a > 0, a ≠ 1, рост/убывание и положительность значений. Решать простые показательные уравнения и неравенства приведением к одному основанию. Главный вопрос: «при удвоении каждый час сколько будет через полчаса?». Предварительно — [степени и корни](../stepeni-i-korni.html), координаты и неравенства.

## Границы

Самостоятельный `pokazatelnaya-funkciya.html`, два занятия примерно по 25–30 минут. Непрерывная модель с постоянным множителем на единицу времени, смысл действительного показателя через приближения, график a^x, обратные основания, сравнение показателей. Логарифмы и уравнения с несводимыми основаниями — отдельное продолжение. Формальное построение действительной степени и доказательство непрерывности не входят; объясняется идея без заявления о строгом доказательстве. Хранилище не используется.

## Сценарий и интерактивность

1. Сравнить «+10» и «×2» для начального количества 10. Отрицательный момент времени в модели означает восстановление прошлого; дробное время допустимо при явно принятой непрерывной модели.
2. Исследование модели: множитель q из 1/2, 4/5, 1, 5/4, 2; время t от −2 до 4 с шагом 0,5. Ползунок показывает количество, отношение соседних шагов и таблицу целых часов. q = 1 — постоянный случай, допустимый в модели, отдельно от определения показательной функции.
3. График y = a^x: выбор a из 1/3, 1/2, 4/5, 1, 5/4, 2, 3; x от −3 до 3 с шагом 0,5. Линейные оси с фиксированным окном x ∈ [−3;3], y ∈ [0;9], обрезанные высокие ветви явно обозначены. Отдельные подписи точки (x; a^x) и общей (0;1). a = 1 — доступное сравнение, явно названное постоянной функцией. Статичный рисунок и объяснение доступны без JS.
4. Почему a > 0 и a ≠ 1; область определения R, значения (0;+∞), ось y = 0 не достигается. При a > 1 рост, при 0 < a < 1 убывание. Объяснение через множитель a^h при h > 0; связь обратных оснований отражением.
5. Простые уравнения/неравенства с равными основаниями и объяснение смены знака при убывании. Два предсказания и восемь задач; безопасный числовой ввод и выбор, подсказка/решение у каждого. Шпаргалка и скрываемые заметки родителю.

## Критерии готовности

- [x] Условия основания и модели, действительный показатель, рост/убывание, положительность и особый случай a = 1 объяснены.
- [x] Оба исследования работают с диска без сети, на границах и при q/a = 1; график не создаёт ложных нулей и сообщает об обрезке.
- [x] Независимые ответы: 10·2³ = 80; 10·(1/2)² = 2,5; 2^x = 1/8 даёт −3; 3^(2x−1) = 1/27 даёт −1; (1/2)^x > (1/2)³ даёт x < 3; 2^(x+1) ≤ 8 даёт x ≤ 2; 2^x = 0 не имеет решений; (−2)^x не определено для всех действительных x.
- [x] Все задания, правильный/неправильный/пустой/недопустимый ввод, дробь, запятая/точка, снятие прежнего статуса и числовой допуск проверены.
- [x] Chrome, 1200 и 390 CSS px, обе темы, клавиатура, отсутствие сети/ошибок JS, отключённый JS и недоступное хранилище проверены.
- [x] Реестр, каталог, README, карта тем, индекс спек и передача обновлены; проверки проекта, diff, staged и истории пройдены.

## Реализация

Спека → самостоятельный HTML в существующем визуальном языке → независимые математические примеры и браузерная матрица → обновление документов → коммит и обычный push. Отдельных зависимостей, сервера, сборки и публикации нет.
