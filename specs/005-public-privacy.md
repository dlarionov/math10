# 005 · Подготовка публичного репозитория

Статус: В работе · разрешена повторная отправка очищенной истории

## Цель и границы

Публичные файлы и доступная через main история не должны содержать личные сведения, индивидуальные результаты занятий, домашние пути, секреты и личные адреса авторов коммитов.

Входят очистка документов и текста уроков, нейтральная локальная Git identity, очистка двух исходных коммитов и проверка перед отправкой. Учебная математика и интерактивные алгоритмы сохраняются.

Не входят переключение видимости проекта, изменение глобального Git-профиля, удаление внешних копий и серверных кешей. Ссылку на сам публичный репозиторий можно оставить. Имена в вымышленных учебных примерах не являются данными участников.

## Критерии

- [x] В документах и уроках нет персонального семейного контекста и индивидуальных статусов обучения.
- [ ] В main нейтральные автор и committer, в том числе в исходных коммитах.
- [ ] Исходные версии файлов очищены вместе с текущими.
- [x] Есть проверка рабочего дерева, staged-снимка и истории без печати найденных значений.
- [x] Локальная конфигурация задаёт нейтральное авторство только для этого проекта.
- [x] Статическая проверка проекта проходит; алгоритмы уроков не изменены.
- [ ] Отправка очищенной main выполняется с точным force-with-lease и проверкой удалённого результата; другие удалённые ветки и теги не изменяются.

## Проверки и ограничения

Проверены рабочие файлы, staged-снимок и три очищенных локальных коммита с 36 историческими blob-объектами; совпадений по правилам сканера нет. Синтетические примеры подтвердили обнаружение семи категорий приватных данных; безопасный технический email допускается. JavaScript и CSS всех четырёх HTML-страниц побайтово совпадают с исходными в обоих исторических снимках. Проверка структуры прошла по 21 документу и 88 ссылкам.

Подготовленная очищенная история сохраняет оба исходных коммита по смыслу; актуальные изменения документов переносятся отдельным коммитом без привязки к прежней приватной истории. Однократная замена main разрешена; результат повторной отправки будет записан после выполнения. При несовпадении ожидаемого удалённого hash отправку останавливает lease.

Автоматический поиск секретов эвристический; отсутствие совпадений не даёт гарантии обнаружения любого произвольного секрета. Удаление старых refs не доказывает физическое удаление объектов или внешних копий на сервере.
