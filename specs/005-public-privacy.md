# 005 · Подготовка публичного репозитория

Статус: В работе

## Цель и границы

Публичные файлы и доступная через main история не должны содержать личные сведения, индивидуальные результаты занятий, домашние пути, секреты и личные адреса авторов коммитов.

Входят очистка документов и текста уроков, нейтральная локальная Git identity, очистка двух исходных коммитов и проверка перед отправкой. Учебная математика и интерактивные алгоритмы сохраняются.

Не входят переключение видимости проекта, изменение глобального Git-профиля, удаление внешних копий и серверных кешей. Ссылку на сам публичный репозиторий можно оставить. Имена в вымышленных учебных примерах не являются данными участников.

## Критерии

- [ ] В документах и уроках нет персонального семейного контекста и индивидуальных статусов обучения.
- [ ] В доступной через main истории нейтральные автор и committer, в том числе в исходных коммитах.
- [ ] Исходные версии файлов очищены вместе с текущими; приватные данные не оставлены в предыдущих снимках.
- [ ] Есть проверка рабочего дерева, staged-снимка и истории без печати найденных значений.
- [ ] Локальная конфигурация задаёт нейтральное авторство только для этого проекта.
- [ ] Статическая проверка проекта проходит; алгоритмы уроков не изменены.
- [ ] Отправка использует точный force-with-lease для main; другие удалённые ветки и теги не переписываются.

## Проверки и ограничения

Проверки и результат синхронизации будут записаны после выполнения. Автоматический поиск секретов эвристический; отсутствие совпадений не даёт гарантии обнаружения любого произвольного секрета. Удаление старых refs не доказывает физическое удаление объектов или внешних копий на сервере.
