# 019 · Равносильные преобразования и корни уравнения

Статус: Реализована

## Цель и контекст

После урока учащийся различает равносильный переход и переход, который может добавить или потерять корни; сохраняет область допустимых значений и объясняет проверку в исходном уравнении. Нужны подстановка, действия со скобками, квадрат и арифметический квадратный корень; определения повторяются внутри.

Главный вопрос: почему после верного вычисления может получиться неверный ответ? Файл: ravnosilnye-preobrazovaniya.html. Ориентир — два занятия по 20–25 минут.

## Границы

Уравнение, корень, ОДЗ, равносильность, следствие; прибавление и ненулевой множитель; квадрат, деление на выражение, умножение на выражение, сокращение дроби. Без общего решателя произвольных уравнений, исполнения ввода, параметрических задач и углублённого режима.

## Сценарий и интерактивность

1. Контрпример x = −2 → x² = 4, определения множеств решений и стрелок.
2. Мастерская: x = a → x² = a²; x(x − a) = 0 → x − a = 0; x = a → (x − a)(x − b) = 0. Ползунки a и b от −3 до 3 с шагом 0,5. Две числовые прямые и текст показывают корни до/после, добавленные/потерянные значения; случаи a = 0 и a = b обязательны. В режиме деления явно рассматривается ошибочная запись без сохранения условия x ≠ 0 и объясняется разбиение на случаи.
3. Безопасные переходы с условиями; возведение в квадрат и проверка; потеря корня при делении; исходная ОДЗ после сокращения.
4. Восемь заданий с немедленной проверкой, подсказкой и решением; числовой ввод и выбор множества решений. Точка/запятая, дробь и минус «−», пустой и недопустимый ввод. Изменение ответа снимает прежнюю отметку.
5. Поясняющие двусторонние связи со степенями/корнями и логарифмами; отдельный переход к графикам. Все необходимые определения внутри урока.

## Проверки и ограничения

План независимых примеров: квадрат при a = −2 даёт {−2; 2}; при a = 0 — {0}. Деление при a = 3 теряет 0; при a = 0 множества случайно совпадают, но деление на ноль недопустимо. Умножение при a = 1, b = −2 добавляет −2; при a = b не добавляет корней. Практика: √(x + 2) = x имеет корень 2; x(x − 3) = 0 имеет 0 и 3; (x² − 4)/(x − 2) = 4 не имеет корней; 3x + 5 = 11 имеет 2; из x = −3 после квадрата добавляется 3; (x − 1)² = 0 сохраняет единственный корень 1 после деления по ошибочной схеме, но требует отдельного разбора; 1/(x − 2) = 0 не имеет корней; √(x + 6) = x имеет корень 3 и постороннее значение −2 после квадрата.
