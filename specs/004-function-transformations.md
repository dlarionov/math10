# 004 · Преобразования графиков

Статус: Реализована

## Цель

Ученица предсказывает, как изменится знакомый график при изменении формулы, и объясняет разницу между f(x) + b и f(x + b). Находит новую координату известной точки и восстанавливает простое преобразование по рисунку.

Основной вопрос: «Почему плюс внутри скобок сдвигает график влево?» Предварительные знания: координаты, функция как соответствие входа и выхода, графики x² и |x|; понятие области определения кратко повторить.

Файл урока: [grafiki-preobrazovaniya.html](../grafiki-preobrazovaniya.html). Ориентир — два занятия по 20–30 минут.

## Границы

Входят вертикальный и горизонтальный сдвиги, растяжение/сжатие по вертикали, отражение относительно осей, связь графика и координат точки. Основная модель: y = A · f(x − h) + v; отдельно объясняем f(−x).

Не входят общий множитель внутри аргумента f(Bx), композиции с модулем, обратная функция, производная и формальный анализ сложных областей определения. Не перегружаем урок всеми преобразованиями сразу.

## Сценарий и интерактивность

1. Сравнить высоты точек y = x² и y = x² + 2: тот же вход, другой выход. Вертикальный сдвиг.
2. Зафиксировать точку на исходном графике и спросить, какой новый x даёт прежний вход при f(x − h). Вывести отображение (x₀, y₀) → (x₀ + h, y₀ + v).
3. Умножить выход на A; рассмотреть A = 2, 1/2, −1 и 0. При A = 0 получается y = v на области определения, а не «отражённый график».
4. Отражение f(−x): точка (x₀, y₀) переходит в (−x₀, y₀). На x² отражение незаметно, поэтому добавить несимметричный пример x³ или √x с объяснением области определения.
5. Мастерская: выбор x², |x| и √x; ползунки h и v от −4 до 4, A от −3 до 3 с шагом 0,5. Исходный и новый графики различимы по подписи и стилю линий. Координаты выбранной точки обновляются по (x₀ + h, A·y₀ + v).
6. «Предскажи, затем проверь»: до применения изменения предложить направление/координату. Итоговые задания и шпаргалка с типичными ошибками.

Случаи выхода точки за окно объяснить подписью или индикатором; не рисовать ложную точку на краю. Для √x не вычислять корень при отрицательном аргументе. Оси, сетка и подписи адаптируются к экрану.

## Независимые контрольные примеры

| Пример | Ожидаемый результат |
| --- | --- |
| Вершина y = (x − 3)² + 2 | (3; 2) |
| y = f(x + 2), исходная точка (1; 4) | (−1; 4) |
| y = −2f(x − 1) + 3, исходная точка (2; 5) | (3; −7) |
| y = f(−x), исходная точка (2; 5) | (−2; 5) |
| y = √(x − 2) | Область x ≥ 2; начало (2; 0) |
| A = 0, h = 2, v = 3 при базовой √x | y = 3 при x ≥ 2 |
| y = (x + 2)², значение при x = 0 | 4 |

## План реализации

Самостоятельный HTML с CSS-токенами существующей тетради; SVG или Canvas для графика без библиотек. Один параметризованный вычислитель с явными областями определения. Сначала реализовать понятный перенос одной точки, затем полный график и задания.

Принятые детали: SVG с фиксированным окном координат и явным сообщением о точках за его пределами; исходная линия пунктирная, преобразованная сплошная. Координаты точки меняются отдельным ползунком. Для √x область после сдвига сохраняется и при A = 0. Локальное хранилище сохраняет только настройки заметок и отметки разделов, без индивидуальных результатов в Git. Подсказки и решения записаны непосредственно в HTML и доступны без JavaScript.
