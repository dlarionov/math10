# 000 · Основа проекта

Статус: В работе

## Цель

Перевести набор локальных уроков в сопровождаемый проект с облегчённой SDD и историей в предоставленном репозитории. Сохранить простой запуск и существующие материалы.

Основание: проекту нужны воспроизводимый процесс разработки, спецификации и сохранение результата в Git.

## Границы

Входят: инструкции, конституция, процесс, карта тем, исходные спеки трёх уроков, следующая спека, передача сессии, воспроизводимая статическая проверка, Git и первый push.

Не входят: новый урок, переписывание существующих страниц, CI, hosting, лицензирование от имени владельца, перенос пользовательских данных. Репозиторий на момент `git ls-remote` доступен и не содержит опубликованных refs.

## Критерии готовности

- [x] Все документы связаны из README и не противоречат разрешениям родителя.
- [x] Конституция определяет учебные, математические, технические и процессные принципы.
- [x] Существенная работа начинается со спеки; мелкая правка не требует полного цикла документов.
- [x] Есть честное описание исходных уроков и будущая спека графиков без фиктивного статуса реализации.
- [x] Указаны правила новых сессий и подготовлен стартовый запрос.
- [x] Статическая проверка проходит; границы проверки описаны.
- [x] Три урока сохранены без изменения поведения.
- [ ] Изменения закоммичены и отправлены в origin/main; результат подтверждён Git.
