# 011 · Логарифмы

Статус: Реализована

## Цель и контекст

После степеней и показательной функции научиться читать логарифм как неизвестный показатель, объяснять ограничения и решать простые задачи. Основной вопрос: через сколько шагов удвоения получится множитель 8?

## Границы

Самостоятельный `logarifmy.html`, два занятия по 25–30 минут. Определение, положительное основание не 1, положительный аргумент, график, произведение/частное/степень, смена основания, простые уравнения и сравнения. Без сложных уравнений, параметров и общего метода логарифмических неравенств. Связь с действительной степенью объясняется на уровне предыдущего урока.

## Сценарий и интерактивность

Вопрос об удвоении → обратный вопрос к степени → определение и ограничения → исследование показателя → график → свойства через сложение показателей → разобранные примеры → восемь задач и шпаргалка. Перерыв после графика.

В первом исследовании основание 1/2, 2, 3 или 10 и показатель от −3 до 3 с шагом 0,5 задают аргумент; обе записи меняются одновременно. Во втором основание и положительный аргумент из конечного набора меняют точку на графике логарифма. Видимое окно явно обозначено, обрезанная кривая имеет подпись. Два предсказания с подсказками/решениями предшествуют действиям. Заметки родителю скрываются, ответы и настройки не сохраняются.

## Критерии готовности

- [x] Условия всех свойств и различие логарифма суммы/произведения объяснены; ноль и отрицательные аргументы исключены.
- [x] Оба исследования работают с клавиатуры, при крайних значениях и на 390 CSS px.
- [x] Восемь задач имеют проверку, подсказку, решение и полезную реакцию на ошибку; числовой ввод принимает дробь, точку и запятую без исполнения кода.
- [x] Независимые ответы: log₂(1/8)=−3; log₉3=1/2; log₅1=0; log₂3+log₂(8/3)=3; log₃(x−1)=2 даёт x=10 с x>1; log₀,₅x>1 даёт 0<x<1/2; log₂(3+5)=3, но log₂3+log₂5=log₂15; log₁4 не определён.
- [x] Страница автономна, без сети; текст/решения доступны без JS, недоступное хранилище не мешает.
- [x] Каталог, реестр, карта тем и передача сессии обновлены; проверки проекта, приватности, коммит и обычный push выполнены.

## Реализация

Использовать визуальные токены предыдущего урока, встроенные SVG и обычный JS. Сначала подготовить страницу, затем независимые математические и браузерные проверки; фактические результаты записать ниже. Символьного решателя нет, числовые ответы с допуском 0,0005 при округлении до 0,001.
