Последовательности и прогрессии

Каждый раз прибавлять три или каждый раз умножать на два — разные правила. Как по правилу найти сотое число? А сумму первых ста?

Два занятия по 20–30 минут. Можно остановиться после арифметической прогрессии.

1. Номер — не значение

Представь узор, который строят по шагам. На первом шаге три точки, на каждом следующем добавляют ещё три. Получается 3, 6, 9, 12, … . Чтобы узнать число точек, сначала выбираешь номер шага.

Числовая последовательность задаёт число для каждого натурального номера 1, 2, 3, … . Число на выбранном месте называют членом последовательности. Запись aₙ читается «а с индексом эн»: это член с номером n, а не произведение a и n.

a₁ = 3, a₂ = 6, a₃ = 9, …Номер n — положительное целое число. Значение aₙ может быть отрицательным, нулевым или дробным. Например, у последовательности 1, 1/2, 1/3, … номер 3 соответствует числу 1/3.

Правило нужно знать. По трём числам 2, 4, 8 нельзя однозначно определить четвёртое: можно продолжить удвоением, а можно задать другое правило. В наших задачах правило будет указано.

Степень напоминает повторное умножение: 2³ = 2 · 2 · 2. Нулевая степень ненулевого числа равна 1. Этих фактов и обычных действий с числами достаточно для начала.

Для вас

Попросите различить два вопроса: «Какой номер?» и «Какое число на этом месте?» Не называйте угадывание закономерности доказательством её единственности.

2. Сравни правила

Здесь можно прибавлять одну и ту же разность d или умножать на один и тот же множитель q. Правило постоянной прибавки задаёт арифметическую прогрессию. Правило постоянного умножения задаёт геометрическую прогрессию, если множитель и все члены ненулевые.

Сначала предскажи: что получится при прибавлении нуля? А при умножении на −1?

Подсказка

Примени действие несколько раз к числу 3.

Решение

Прибавление нуля оставит 3, 3, 3, … . Умножение на −1 даст 3, −3, 3, −3, … : знак будет чередоваться.

Мастерская последовательностей

Горизонталь — номер, вертикаль — значение члена. Последний член выделен крупной точкой. Масштаб по вертикали меняется; его метки округлены. Точки не соединены: дробных номеров здесь нет.

Прибавляем 3. Шестой член равен 18; сумма первых шести членов равна 63.

Попросите сначала назвать ожидаемый результат, потом изменить контрол. Например: «Если разность отрицательная, что будет с точками?» Размер рисунка меняется вместе с масштабом; сравнивайте также числа в таблице.

3. Каждый раз прибавляем

Арифметическая прогрессия — последовательность, в которой каждый член, начиная со второго, получается из предыдущего прибавлением одного и того же числа d. Его называют разностью прогрессии.

Чтобы от первого члена попасть к четвёртому, нужно три прибавления. Чтобы попасть к n-му — n − 1 прибавлений:

aₙ = a₁ + (n − 1)d, n = 1, 2, 3, …

Разность может быть положительной, отрицательной или нулевой. При d = 0 все члены равны. При n = 1 прибавлений ещё не было, поэтому формула возвращает a₁.

Если a₁ = 3 и d = 4, то a₇ = 3 + 6 · 4 = 27. Здесь шесть переходов, хотя номер последнего члена равен семи.

Сумма: сложим с двух концов

Обозначим сумму первых n членов буквой Sₙ. Запишем один и тот же список в прямом и обратном порядке. В каждой паре получится a₁ + aₙ:

Sₙ = a₁ + a₂ + … + aₙ
Sₙ = aₙ + aₙ₋₁ + … + a₁
2Sₙ = n(a₁ + aₙ)
Sₙ = n(a₁ + aₙ)2 = n(2a₁ + (n − 1)d)2

Почему пары равны? Второй член больше первого на d, а предпоследний меньше последнего на d: изменения компенсируются. Это работает и при отрицательном d.

Для 1 + 2 + … + 100 каждая пара крайних чисел даёт 101. Поэтому S₁₀₀ = 100 · 101 / 2 = 5050. Для нечётного числа членов метод тоже работает: мы складываем два списка, так что средний член учитывается дважды.

aₙ — одно число на выбранном месте. Sₙ — сумма всего начала последовательности. Они отвечают на разные вопросы.

Для вас

До формулы попросите сложить 3 + 7 + 11 + 15 + 19, соединяя крайние числа. Затем спросите, почему на четвёртом месте только три прибавления.

4. Каждый раз умножаем

Геометрическая прогрессия — последовательность ненулевых чисел, в которой каждый член, начиная со второго, получается умножением предыдущего на одно и то же ненулевое число q. Его школьное название — знаменатель геометрической прогрессии; здесь q работает как постоянный множитель.

Например, 5, 10, 20, 40, … имеет q = 2. Последовательность 8, 4, 2, 1, … имеет q = 1/2. При отрицательном q знаки чередуются: 3, −6, 12, −24, … .

bₙ = b₁qn−1, b₁ ≠ 0, q ≠ 0, n = 1, 2, 3, …

Снова n − 1 переходов. При n = 1 степень равна нулю и b₁q⁰ = b₁. При q = 1 все члены одинаковы. Нулевая последовательность 0, 0, 0, … не является геометрической прогрессией по данному определению: отношение соседних членов 0/0 не определено.

Сумма: сдвинем список умножением

Запишем сумму, затем умножим её на q. Почти все слагаемые совпадут:

Sₙ = b₁ + b₁q + … + b₁qn−1
qSₙ = b₁q + b₁q² + … + b₁qn
Sₙ − qSₙ = b₁ − b₁qn

Если q ≠ 1, можно разделить на 1 − q. Если q = 1, делить на ноль нельзя — складываем n одинаковых чисел.

Sₙ = b₁ · 1 − qn1 − q, q ≠ 1.
При q = 1: Sₙ = nb₁.

Для 5 + 10 + 20 + 40 + 80 + 160 получаем S₆ = 5 · (1 − 2⁶)/(1 − 2) = 315. Последний член — 160, сумма — 315. При q > 1 оба числа в дроби отрицательные; это не ошибка знака.

При q = 1/2 сумма первых четырёх членов 8, 4, 2, 1 равна 15. Членов здесь ровно четыре: про бесконечную сумму мы ничего не утверждаем.

Для вас

Попросите выписать S₃ и qS₃ и зачеркнуть одинаковые слагаемые. Для q = −2 полезно отдельно проверить знак последнего члена. Последовательности с отрицательным q не обязаны возрастать или убывать.

5. Найди член или сумму

Сначала определи правило и вопрос задачи. Числовой ответ можно записать целым числом, с запятой/точкой или простой дробью, например 15/2. В этих задачах округление не нужно.

1. Дальний член

В арифметической прогрессии a₁ = 3 и d = 4. Найди a₇.

Подсказка

К первому члену прибавь разность n − 1 раз.

Решение

a₇ = 3 + (7 − 1) · 4 = 27.

2. Можно ли угадать однозначно?

Известны только первые числа 2, 4, 8. Правило не указано. Обязательно ли следующее число равно 16?

Подсказка

Можно ли после 2, 4, 8 начать каждый раз прибавлять 1?

Решение

Однозначного ответа нет. Правило удвоения даст 16, а правило «сначала 2, 4, 8, затем каждый раз прибавлять 1» даст 9. Оба согласуются с первыми тремя числами.

3. Убывающая прогрессия

a₁ = 20, d = −3. Найди сумму первых шести членов арифметической прогрессии.

Подсказка

Последний член равен 20 − 5 · 3. Затем сложи первый с последним.

Решение

a₆ = 5. S₆ = 6 · (20 + 5)/2 = 75. Проверка: 20 + 17 + 14 + 11 + 8 + 5 = 75.

4. Сто чисел

Найди сумму всех целых чисел от 1 до 100 включительно.

Подсказка

Членов сто, первый 1, последний 100.

Решение

S₁₀₀ = 100 · (1 + 100)/2 = 5050. Можно составить 50 пар по 101.

5. Удвоения

В геометрической прогрессии b₁ = 5 и q = 2. Найди b₆.

Подсказка

В показателе степени нужен номер минус один.

Решение

b₆ = 5 · 2⁵ = 160. Число 320 получилось бы после шести удвоений, то есть на седьмом месте.

6. Каждый раз пополам

b₁ = 8, q = 1/2. Найди сумму первых четырёх членов геометрической прогрессии.

Подсказка

Сначала 8, потом 4. Какие два числа дальше?

Решение

S₄ = 8 + 4 + 2 + 1 = 15. По формуле: 8 · (1 − (1/2)⁴)/(1 − 1/2) = 15.

7. Знак тоже часть правила

b₁ = 3, q = −2. Найди четвёртый член геометрической прогрессии.

Подсказка

Выпиши 3, −6, … или посчитай 3 · (−2)³.

Решение

3, −6, 12, −24. Значит, b₄ = −24. Скобки в (−2)³ сохраняют отрицательное основание.

8. Сколько всего?

На шести шагах получены значения 5, 10, 20, 40, 80, 160. Какова их сумма?

Подсказка

Проверь, отвечает ли 160 на вопрос «всего».

Решение

5 + 10 + 20 + 40 + 80 + 160 = 315. Либо S₆ = 5 · (1 − 2⁶)/(1 − 2) = 315. Число 160 — только последний член.

Для вас

Попросите перед вычислением назвать, что требуется: член или сумма. Ошибки на один шаг удобно разбирать коротким списком из трёх-четырёх чисел.

6. Где эта идея встречается дальше

Короткая памятка: постоянная разность — арифметическая прогрессия; постоянный ненулевой множитель и ненулевые члены — геометрическая. На месте n уже сделано n − 1 переходов. Для суммы сначала выбери нужный тип прогрессии.

Показательная функция →
При q > 0 значения bₙ = b₁qⁿ⁻¹ лежат на графике N(t) = b₁qᵗ в моменты t = n − 1. Последовательность берёт отдельные шаги, модель функции допускает и дробное время. При q = 1 функция постоянна; при q < 0 такой действительной показательной функции для всех t нет.

Логарифмы →
Здесь по номеру мы находили значение. Логарифм помогает поставить обратный вопрос: сколько умножений понадобилось, чтобы получить известное положительное значение?

Степени и корни →
Если запись qⁿ⁻¹ пока непривычна, можно отдельно разобрать смысл показателя и правила действий.

Эти переходы — продолжение по желанию. Определения и формулы текущего урока собраны на этой странице.

Для вас

Уточните начало отсчёта: первый член соответствует нулю выполненных переходов. Для 5 · 2ᵗ при t = 0 получаем 5, а не 10. Это связывает две темы без необходимости пройти их в строгом порядке.
