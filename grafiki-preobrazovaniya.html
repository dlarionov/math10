График меняется.
Что меняет формула?

Плюс снаружи поднимает график. Плюс внутри скобок двигает его влево. Разберёмся, откуда эта разница, и научимся переносить целый график, следя всего за одной точкой.

Нужно уметь: читать координаты, подставлять число в формулу, узнавать y = x² и y = |x|.

Занятие 1 · шаг 1

Снаружи меняется выход

Функция — правило: ты даёшь число x на вход, а получаешь f(x) на выходе. Точка (x; f(x)) показывает эту пару на графике. Область определения — все числа, которые можно подать на вход.

Пусть f(x) = x². Если к готовому результату прибавить 2, то каждый выход станет на 2 больше. Вход остаётся прежним.

y = f(x) + 2:   (x₀; y₀) → (x₀; y₀ + 2)

Значит, график целиком поднимется на 2 единицы. Вычитание снаружи опускает его.

Для вас

Начните с вопроса: «Если у каждой точки увеличить только вторую координату, куда они пойдут?» Пусть сначала будет ответ словами, затем формула.

Напомните: в координатах (x; y) сначала идём по горизонтали, затем по вертикали.

Шаг 2 · почему знак будто наоборот?

Внутри меняется вход

Теперь рассмотрим y = f(x − 3). Внутрь f поступает число x − 3. Чтобы функция снова получила прежний вход x₀, нужно решить:

x − 3 = x₀   ⇒   x = x₀ + 3

Прежняя высота y₀ теперь достигается на 3 единицы правее. Поэтому f(x − 3) — сдвиг вправо на 3.

Для y = x² вершина получается при входе 0. Для y = (x − 3)² внутри тоже должен быть 0: x − 3 = 0, значит x = 3. Вершина стала (3; 0).

А для f(x + 2) решаем x + 2 = x₀. Получаем x = x₀ − 2 — сдвиг влево. Это следует из поиска прежнего входа.

y = f(x − h) + v:
(x₀; y₀) → (x₀ + h; y₀ + v)

h может быть отрицательным. Например, f(x + 2) = f(x − (−2)), поэтому h = −2.

Сначала предскажи: куда сдвинется y = f(x + 2)?

Подсказка

Какое x нужно подставить, чтобы x + 2 стало равно прежнему входу x₀?

Решение

x + 2 = x₀, поэтому x = x₀ − 2. Точка (1; 4) перейдёт в (−1; 4).

Для вас

Не торопитесь давать правило «знак наоборот». Попросите найти, при каком x выражение x + 2 станет равно нулю. Это даёт опору, если правило забыто.

В конце первого занятия предложите набросать x², x² + 2 и (x + 2)² на одном листе.

Занятие 2 · шаг 3

Умножаем все высоты

В y = A·f(x) множитель A действует на выход. Координата x остаётся прежней, а y умножается на A.

y = A·f(x):   (x₀; y₀) → (x₀; A·y₀)
AЧто происходит с высотойТочка (2; 4) станет
2Расстояние до оси Ox удваивается(2; 8)
½Расстояние до оси Ox уменьшается вдвое(2; 2)
−1Высота меняет знак: отражение относительно Ox(2; −4)
0Все допустимые выходы становятся нулём(2; 0)

При |A| > 1 — растяжение от оси Ox; при 0 < |A| < 1 — сжатие к ней. Если A < 0, добавляется отражение относительно Ox. Коэффициент −2 отражает и удваивает расстояние до оси.

Собираем преобразование

y = A·f(x − h) + v:
(x₀; y₀) → (x₀ + h; A·y₀ + v)

Сначала умножь прежнюю высоту на A, затем прибавь v. Значения A·y₀ + v и A·(y₀ + v) обычно различаются.

На исходном графике есть точка (2; 5). В y = −2f(x − 1) + 3 она станет (2 + 1; −2 · 5 + 3) = (3; −7).

При A = 0 не забываем область определения

В y = 0·f(x − h) + v все допустимые высоты равны v. Но умножение на ноль не делает запрещённые входы разрешёнными.

Например, в y = 0·√(x − 2) + 3 нужно x ≥ 2. Получается горизонтальный луч y = 3 при x ≥ 2. При x = 1 выражение не определено.

Для вас

Спросите про точку с отрицательной высотой: «Если умножить −3 на 2, она станет выше или ниже?» Растяжение означает удаление от оси, а не всегда движение вверх.

Случай A = 0 лучше проверить на корне: на параболе ограничение области не видно.

Шаг 4 · два разных зеркала

Минус снаружи и минус внутри

−f(x) меняет знак высоты, то есть отражает график относительно оси Ox. f(−x) меняет знак входа: прежняя высота y₀ получается при −x = x₀, то есть x = −x₀. Это отражение относительно оси Oy.

−f(x):   (x₀; y₀) → (x₀; −y₀)
f(−x):   (x₀; y₀) → (−x₀; y₀)

На графике x² второе отражение незаметно, потому что он уже симметричен относительно Oy. Чтобы увидеть разницу, возьмём √x.

Объясни предсказание: почему точка (2; 5) для f(−x) переходит в (−2; 5)?

Подсказка

Отдельно вычисли −x, когда x = −2.

Решение

−(−2) = 2. Функция получает прежний вход 2 и возвращает прежнюю высоту 5. Меняется только первая координата.

Для вас

Попросите объяснить, почему f(−x) и −f(x) совпадают для f(x) = x, но не для f(x) = x². Это необязательный вопрос для обсуждения.

На схеме корня видны сторона области определения и зеркальность; точные координаты проверяются формулой.

Шаг 5 · исследуй самостоятельно

Мастерская графиков

Выбери исходную функцию. Сначала предскажи, куда пойдёт её отмеченная точка, затем меняй параметры и сравнивай. Перемещай x₀, чтобы проследить другие точки.

Исходный: пунктир, полая точка PНовый: сплошной, точка Q
y = x²

P(x₀; y₀) → Q(x₀ + h; A·y₀ + v)

Окно рисунка фиксировано: x от −6 до 6, y от −5 до 7. Часть графика может выходить за рамку. Точка за пределами окна не подменяется точкой на краю.

Три опыта для мастерской

1. Выбери x², A = 1, h = −2, v = 0. Где вершина? Почему плюс в (x + 2)² двигает её влево?

2. Выбери |x| и меняй A: 2 → 0,5 → −1. Чем сжатие отличается от отражения?

3. Нажми «Пример: корень и A = 0». Почему горизонтальная линия начинается только при x = 2?

Для вас

Меняйте один параметр за раз. Полезно проговаривать: «h меняет первую координату, A и v — вторую».

В отличие от сдвигов, отражение относительно Oy показано отдельно в шаге 4: мастерская управляет формой A·f(x − h) + v.

Шаг 6 · проверь понимание

От рисунка к координатам

Реши сначала в тетради. Для координат введи x и y в отдельные поля. Можно использовать десятичную запятую, точку или обычную дробь.

1. Найди координаты вершины y = (x − 3)² + 2.

Подсказка

Исходная вершина x² — (0; 0). Найди h и v.

Решение

h = 3, v = 2. Вершина переходит в (0 + 3; 0 + 2) = (3; 2).

2. На y = f(x) есть точка (1; 4). Куда она перейдёт на y = f(x + 2)?

Подсказка

Приравняй новый вход x + 2 к прежнему 1.

Решение

x + 2 = 1, значит x = −1. Высота прежняя, поэтому точка (−1; 4).

3. Перенеси точку (2; 5) на график y = −2f(x − 1) + 3.

Подсказка

Первая координата x₀ + h, вторая A·y₀ + v.

Решение

x = 2 + 1 = 3, y = −2 · 5 + 3 = −7. Получаем (3; −7).

4. На исходном графике отмечена точка (2; 5). Куда она перейдёт при отражении y = f(−x)?

Подсказка

Отражение относительно Oy меняет первую координату.

Решение

(2; 5) → (−2; 5). Высота не меняется.

5. Каково наименьшее допустимое x для y = √(x − 2)?

Подсказка

Выражение под квадратным корнем должно быть неотрицательным.

Решение

x − 2 ≥ 0, то есть x ≥ 2. Наименьшее значение 2; график начинается в (2; 0).

6. Чему равно выражение y = 0·√(x − 2) + 3 при x = 1?

Подсказка

Разрешён ли вход x = 1 для √(x − 2)?

Решение

Под корнем 1 − 2 = −1. В действительных числах такой корень не определён; множитель 0 этого не меняет.

7. Найди значение y = (x + 2)² при x = 0.

Подсказка

Подставь x = 0. Двойка находится внутри квадрата.

Решение

y = (0 + 2)² = 4. Это не y = x² + 2, где при x = 0 получилось бы 2.

8. Во что превратится точка (2; 6), если заменить f(x) на ½f(x)?

Подсказка

Сжатие по вертикали делит только высоту.

Решение

x = 2, y = ½ · 6 = 3. Точка (2; 3).

Два вопроса без подсчёта баллов

Объясни своими словами, почему y = f(x + 2) и y = f(x) + 2 обычно дают разные графики.

С чем сравнить объяснение

В первом случае меняется вход: прежняя высота возникает при x, уменьшенном на 2. Во втором случае вход прежний, но каждый выход увеличен на 2.

Предскажи, почему отражение x² относительно Oy не видно, а отражение √x видно.

С чем сравнить объяснение

(−x)² = x², поэтому парабола уже симметрична. А √x определён справа от нуля; √(−x) — слева. Его область и рисунок отражаются.

Для вас

Здесь восемь итоговых задач. Если числа получаются верно, попросите объяснить выбор знака или найти исходную точку по новой.

Одна точка подскажет весь график

Снаружи — выход

f(x) + v:   y₀ → y₀ + v

A·f(x):   y₀ → A·y₀

A < 0 добавляет отражение относительно Ox.

Внутри — вход

f(x − h):   x₀ → x₀ + h

f(−x):   x₀ → −x₀

Для сдвига приравняй новый аргумент к прежнему входу.

Общая формула

A·f(x − h) + v

(x₀; y₀) → (x₀ + h; A·y₀ + v)

Сначала масштаб высоты, затем вертикальный сдвиг. Проверяй область определения.

Три ловушки

  • (x + 2)² и x² + 2 — разные преобразования.
  • −f(x) отражает относительно Ox, f(−x) — относительно Oy.
  • A = 0 не разрешает входы, на которых исходное выражение не определено.
